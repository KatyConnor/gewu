# findings 发现库文件约定

> 本目录在 Agent 初始化 `.lpu/` 时从 `lpu/init/findings/` 创建。
> 发现库是 LPU 的原始证据层：findings 记"发现了什么+证据"，成文文档记"组织后的结论"。

## 文件约定（固定七个文件，S 阶段对应产出）

| 文件 | 阶段 | 内容 |
|---|---|---|
| RECON.md | S0 | 侦察报告：技术栈/规模/入口清单/模块拆分/危险信号 |
| C-code.md | S2 | 代码维发现（含 S1 骨架的模块清单与依赖邻接表） |
| D-data.md | S2 | 数据维发现 |
| F-function.md | S2 | 功能维发现（含入口全景） |
| K-knowledge.md | S2 | 知识维发现（术语/规则/魔法值） |
| P-process.md | S2 | 流程维发现（状态机/主流程/时序） |
| X-conflicts.md | S3 | 冲突登记与定性（XF-###） |

## 条目格式（全库统一）

```
### F-{{维度}}-{{序号}} {{一句话结论}} [置信度]
【证据】{{路径:行号 或 表.列}}
【备注】{{可选：可疑性/关联条目/被推翻记录}}
状态: active / 已推翻(原因+新证据)
```

规则：
1. 每条必有【证据】行（红线 R1）；
2. 推翻不删除，改状态并注明（GEN-008）；
3. 条目只增不改语义——语义变化 = 新条目 + 旧条目推翻；
4. 每个文件头部维护"本文件条目统计：active n / 推翻 m"。
