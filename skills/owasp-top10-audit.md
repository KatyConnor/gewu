# 技能模块：owasp_top10_audit

> OWASP TOP10 安全审计，针对代码与系统进行白盒安全审计。

## 1. 技能描述

本技能基于 OWASP TOP10（2021 最新版）对代码与系统开展白盒安全审计，覆盖注入、XSS、CSRF、SSRF、反序列化、越权访问、敏感数据泄露、安全配置错误等核心漏洞类型。输出结构化安全审计报告，含漏洞类型、风险等级、修复方案与代码示例。

## 2. 触发条件

- 输入包含「OWASP」「安全审计」「代码审计」「注入」「XSS」「CSRF」等关键词
- 提供源代码 / 系统描述 / API 契约
- 已明确审计范围（哪些模块、哪些接口、哪些代码路径）

## 3. 执行步骤

1. **审计范围确认**：梳理待审计的代码模块、接口清单、数据流图。
2. **OWASP TOP10 逐项核查**：
   - A01 失效的访问控制（越权访问、垂直越权、水平越权）
   - A02 加密机制失效（明文传输、弱算法、密钥管理）
   - A03 注入（SQL/NoSQL/Command/LDAP 注入）
   - A04 不安全设计（业务逻辑缺陷）
   - A05 安全配置错误（默认配置、错误信息泄露）
   - A06 易受攻击的组件（依赖漏洞）
   - A07 身份认证失败（弱口令、会话固定）
   - A08 软件与数据完整性失效（反序列化、未签名更新）
   - A09 安全日志监控失效（关键操作未记录）
   - A10 服务端请求伪造（SSRF）
3. **代码级复核**：对疑似漏洞点逐行复核，确认可利用性。
4. **风险等级评定**：CVSS 3.1 评分 + 业务影响双重评定。
5. **修复方案输出**：代码级修复示例 + 配置加固建议 + 测试用例。
6. **依赖漏洞扫描**：使用 SCA 工具扫描第三方依赖漏洞。
7. **输出审计报告**：漏洞清单 + 修复方案 + 优先级 + 复测计划。

## 4. 输入规范

```yaml
任务类型: OWASP TOP10 安全审计
审计范围:
  源代码: [代码仓库链接 + 分支]
  系统描述: [架构图 + 数据流图]
  API契约: [OpenAPI 文档]
  配置文件: [应用配置 + 中间件配置]
审计深度: 代码级深度审计
重点关注: 越权访问 + 注入 + 反序列化
业务场景: 金融交易系统
```

## 6. 质量标准

- OWASP TOP10 每个类别必须给出明确「已核查 / 未发现 / 发现 N 处」结论
- 漏洞必须给出代码级修复示例，可复制粘贴执行
- 严重漏洞必须 24 小时内修复，并通过回归测试
- 审计报告必须包含审计方法、工具版本、规则库版本
- 必须覆盖业务逻辑漏洞，不仅限于技术漏洞

## 7. 风险控制

| 规则 | 内容 |
|------|------|
| RISK-01 | 严重漏洞必须在提测前修复，禁止带病上线 |
| RISK-02 | 涉及个人信息泄露的漏洞必须同步合规专家 |
| RISK-03 | 修复方案必须经过回归测试，禁止引入新风险 |
| RISK-04 | 依赖升级必须通过兼容性测试 |
| RISK-05 | 审计报告含敏感信息必须加密存储 + 权限管控 |
| RISK-06 | 越权访问漏洞必须从架构层面修复，禁止补丁式修复 |
| RISK-07 | 反序列化漏洞必须升级至最新安全版本 |
