# epic_task_breakdown | Epic-Story-Task 拆解

## 1. 技能描述

本技能面向项目管理与敏捷教练，提供从产品 Roadmap 到可执行研发排期的标准化拆解能力。覆盖 Epic → Story → Task 三级分解、WBS 生成、迭代规划、里程碑设定、角色分工、研发排期表输出六大模块，确保研发资源高效配置与进度可控。

## 2. 触发条件

满足以下任一条件即触发：
- 输入包含「Epic 拆解 / Story 拆分 / Task 分解 / WBS / 研发排期」等关键词
- 业务方要求进行迭代规划、研发排期、里程碑设定
- 角色 10 被激活且场景为「迭代规划」或「研发排期」

## 3. 执行步骤

1. **Roadmap 输入确认**：基于角色 02 的产品路线图与功能优先级
2. **Epic 拆解**：将产品 Roadmap 拆解为可独立交付的 Epic（建议 2-4 周一个 Epic）
3. **Story 分解**：将每个 Epic 拆解为用户故事，含验收标准与故事点估算
4. **Task 分解**：将 Story 拆解为可执行任务（建议 ≤2 天 / 任务）
5. **WBS 生成**：构建工作分解结构树
6. **迭代规划**：按敏捷迭代（建议 2 周一个迭代）划分 Story
7. **里程碑设定**：明确 MVP / Beta / GA 等关键里程碑与验收标准
8. **角色分工**：基于团队配置进行任务分配，含主备负责人
9. **研发排期表输出**：含开始日期 + 结束日期 + 负责人 + 依赖关系 + 风险标注
10. **风险控制校验**：标注资源冲突、依赖风险、调整空间

## 4. 输入规范

```yaml
产品 Roadmap: "[来自角色 02 的路线图]"
功能优先级: "P0/P1/P2/P3"
资源约束: "团队规模 8 人，开发 5 / 测试 2 / 设计 1"
技术约束: "私有化部署，3 个月内 MVP"
团队配置: "[角色清单与可用工时]"
上线时间: "3 个月内 MVP，6 个月内 GA"
输出格式: "里程碑计划 + WBS + 排期表"
```

## 5. 输出格式

```markdown
## Epic-Story-Task 拆解结果

### 一、里程碑计划
| 里程碑 | 时间 | 验收标准 | 关键交付物 |

### 二、WBS 分解
- Epic → Story → Task 三级树状结构

### 三、迭代规划
| 迭代号 | 周期 | Story 清单 | 故事点合计 |

### 四、研发排期表
| Task | 开始 | 结束 | 负责人 | 依赖 | 风险 |

### 五、角色分工矩阵
| 角色 | 主负责 Task | 备负责 Task | 工时占比 |

### 六、风险与依赖
- 资源冲突 + 依赖关系 + 风险等级
```

## 6. 质量标准

- Epic 必须可独立交付，建议 2-4 周一个
- Story 必须含验收标准与故事点估算
- Task 必须可执行，建议 ≤2 天 / 任务
- 排期表必须含开始日期 + 结束日期 + 负责人 + 依赖 + 风险五要素
- 关键 Task 必须含主备负责人，避免单点风险
- 排期必须预留 ±10% 缓冲时间应对不确定性
- 里程碑必须含明确验收标准与关键交付物

## 7. 风险控制

| 规则编号 | 风险点 | 控制动作 |
|---------|--------|---------|
| R-01 | Story 颗粒度过大 | 强制 ≤2 天 / Task，超出需再拆 |
| R-02 | 资源单点风险 | 关键 Task 必须含主备负责人 |
| R-03 | 排期无缓冲 | 必须预留 ±10% 缓冲时间 |
| R-04 | 依赖关系未识别 | 排期表必须标注依赖 Task |
| R-05 | 里程碑无验收标准 | 必须含明确验收标准 + 关键交付物 |
| R-06 | 绝对性承诺 | 禁止「保证按时上线」措辞，输出风险标注 |
| R-07 | 调整空间预留不足 | 所有排期附加 ±10% 调整空间 |

## 8. 跨角色协作接口

| 协作角色 | 协作场景 | 传递内容 |
|---------|---------|---------|
| 角色 02 产品经理 | 排期输入 | Roadmap + 功能优先级 + PRD |
| 角色 03 技术架构师 | 技术拆分输入 | 架构设计 + 分阶段落地步骤 |
| 角色 04 全栈开发工程师 | 任务执行 | Task 清单 + 验收标准 + 排期 |
| 角色 06 测试专家 | 测试排期 | Story 验收标准 + 测试 Task |
| 角色 09 SRE 专家 | 部署排期 | 部署 Task + 灰度发布计划 |
| 角色 10 项目管理（自身） | 风险跟踪 | 风险清单 + 依赖关系 |

**输出传递标记**：`[下一环节传递：里程碑计划 + WBS + 排期表 + 角色分工]`
