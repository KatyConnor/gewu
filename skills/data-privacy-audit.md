# 技能模块：data_privacy_audit

> 数据隐私保护审计，覆盖数据全生命周期。

## 1. 技能描述

本技能针对个人信息处理活动开展隐私保护审计，覆盖五大维度：收集最小必要、知情同意、存储与传输加密、跨境传输合规、用户权利保障。对照《个人信息保护法》《数据安全法》《GDPR》输出隐私审计报告，含违规点、整改建议与合规确认结论。

## 2. 触发条件

- 输入包含「数据隐私」「隐私审计」「个人信息」「最小必要」「知情同意」等关键词
- 已提供数据收集清单、使用规则、隐私政策
- 涉及个人信息处理（收集、存储、使用、加工、传输、提供、公开）
- 产品上线前 / 重大版本更新 / 监管检查前必须审计

## 3. 执行步骤

1. **数据处理流程梳理**：绘制个人信息全生命周期流程图（收集→存储→使用→加工→传输→提供→公开→删除）。
2. **最小必要审计**：收集字段是否与业务目的直接相关；是否过度收集（身份证、人脸、位置）；是否遵循「能用非敏感就不用敏感」原则。
3. **知情同意审计**：隐私政策清晰易懂显著；区分一般同意与单独同意；敏感个人信息（生物识别、宗教信仰、医疗健康、金融账户、行踪轨迹、不满 14 岁儿童信息）必须单独同意；撤回同意便捷。
4. **存储与传输加密审计**：传输 TLS 1.2+ 加密；存储脱敏 / 加密（敏感字段必须加密）；密钥管理规范（KMS、轮换）。
5. **跨境传输审计**：是否涉及数据出境；是否完成安全评估 / 标准合同 / 认证；出境数据清单完整。
6. **用户权利保障审计**：查阅、复制、更正、删除、撤回同意、注销账号、可携带权；自动化决策拒绝权；响应时效达标（15 日 / 30 日）。
7. **输出审计报告**：违规点 + 整改建议 + 合规确认结论。

```yaml

业务场景: 电商平台，C 端用户
数据收集清单:
  字段: [手机号、收货地址、支付信息、设备指纹、浏览记录]
```

## 6. 质量标准

- 五大维度必须全部审计，缺一不可
- 违规点必须对应到具体法规条款（条 / 款 / 项）
- 敏感个人信息必须 100% 单独同意 + 加密存储
- 跨境传输必须有明确合规路径（安全评估 / 标准合同 / 认证）
- 用户权利响应时效必须达标（15 日 / 30 日）
- 审计报告必须有法务签字确认

## 7. 风险控制

| 规则 | 内容 |
|------|------|
| RISK-01 | 敏感个人信息未单独同意禁止上线 |
| RISK-02 | 涉及个人信息出境未做安全评估禁止上线 |
| RISK-03 | 加密存储未达标的字段禁止存储真实数据，用户权利响应超时视为合规事故 |
| RISK-04 | 未满 14 岁儿童信息必须有监护人同意 |
| RISK-05 | 自动化决策必须有拒绝机制，隐私政策变更必须重新取得同意 |

## 8. 跨角色协作接口

```yaml
上游角色:
  - 02-产品经理: 提供产品方案、数据收集清单、隐私政策
  - 04-全栈开发: 提供数据处理流程、加密实现、用户权利接口
  - 03-技术架构师: 提供数据存储架构、跨境传输路径
下游角色:
  - 04-全栈开发: 传递整改要求，落实到代码（加密、同意机制、权利接口）
  - 06-测试专家: 传递隐私测试用例要求（同意、撤回、删除、导出）
  - 09-SRE专家: 传递数据存储、访问控制、日志留存要求
  - 10-项目管理: 同步整改进度，纳入合规里程碑
传递字段: [违规编号, 维度, 法规条款, 整改建议, 责任部门, 审计结论]
```
