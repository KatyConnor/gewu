# 安全加固检查清单

> 格物平台生产环境安全检查清单

## 1. 应用安全

### 1.1 认证安全
- [ ] JWT Secret 使用强密码（>= 256 位）
- [ ] Access Token 过期时间 <= 30 分钟
- [ ] Refresh Token 过期时间 <= 7 天
- [ ] 登录失败锁定机制已配置
- [ ] 会话并发控制已启用

### 1.2 授权安全
- [ ] RBAC 权限模型已实现
- [ ] 最小权限原则已遵循
- [ ] 敏感操作需要二次验证
- [ ] API 接口权限控制已配置

### 1.3 密码安全
- [ ] 密码最小长度 >= 8
- [ ] 密码复杂度要求已配置
- [ ] 密码使用 SM3 + Salt 哈希
- [ ] 密码历史记录已保存

### 1.4 输入验证
- [ ] SQL 注入防护已启用
- [ ] XSS 过滤已启用
- [ ] CSRF 防护已启用
- [ ] 文件上传验证已配置

## 2. 数据安全

### 2.1 数据加密
- [ ] 敏感数据使用 SM4-GCM 加密
- [ ] 数据库连接使用 SSL
- [ ] 文件存储使用加密

### 2.2 密钥管理

- [ ] 密钥定期轮换

### 2.3 数据备份
- [ ] 数据库备份已配置
- [ ] 备份加密已启用
- [ ] 备份验证已执行
- [ ] 恢复演练已通过
