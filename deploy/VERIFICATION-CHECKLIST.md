# 生产环境部署验证清单

> 格物平台生产环境上线前验证清单

## 1. 基础设施验证

- [ ] Docker 版本 >= 24.0
- [ ] Docker Compose 版本 >= 2.20
- [ ] Kubernetes 版本 >= 1.27（如使用 K8s）
- [ ] 服务器资源配置符合最低要求（4 核 8GB）
- [ ] 磁盘空间 >= 50GB SSD
- [ ] 网络带宽 >= 100Mbps

## 2. 数据库验证

- [ ] MySQL 8.0 或 OceanBase 4.4.2+ 已安装
- [ ] 数据库字符集: utf8mb4
- [ ] 数据库排序规则: utf8mb4_unicode_ci
- [ ] 最大连接数: >= 200
- [ ] 慢查询日志已开启
- [ ] 数据库备份策略已配置
- [ ] 数据库迁移脚本已执行（Flyway）

## 3. 缓存验证

- [ ] DragonflyDB 或 Redis 已安装
- [ ] 内存限制已配置
- [ ] 持久化策略已配置
- [ ] 连接测试通过

## 4. 消息队列验证（可选）

- [ ] RocketMQ 5.1.4+ 已安装
- [ ] NameServer 和 Broker 已启动
- [ ] 主题已创建

## 5. 应用部署验证

- [ ] Docker 镜像构建成功
- [ ] 容器启动正常
- [ ] 健康检查接口返回 UP
- [ ] 日志输出正常
- [ ] 环境变量配置正确

## 6. 功能验证

- [ ] 用户注册/登录正常
- [ ] JWT Token 生成/验证正常
- [ ] 国密 SM2/SM3/SM4 加解密正常
- [ ] 会话创建/查询正常
- [ ] Agent 配置/执行正常
- [ ] 工作流创建/执行正常
- [ ] AI 对话功能正常
- [ ] 沙箱创建/管理正常

## 7. 性能验证

- [ ] 核心 API P95 < 200ms
- [ ] 非核心 API P95 < 500ms
- [ ] 750 并发下系统稳定
- [ ] HPA 自动扩缩容正常
- [ ] 无内存泄漏
- [ ] 数据库连接池无耗尽

## 8. 安全验证

- [ ] HTTPS 已配置
- [ ] JWT Secret 已更换为强密码
- [ ] 国密密钥已安全存储
- [ ] 敏感配置未硬编码
- [ ] 依赖漏洞扫描通过
- [ ] 等保 2.0 三级合规检查通过

## 9. 监控验证

- [ ] Prometheus 抓取正常
- [ ] Grafana 仪表盘正常
- [ ] 告警规则已配置
- [ ] 日志收集正常
- [ ] 健康检查正常

## 10. 备份与恢复验证

- [ ] 数据库备份脚本正常
- [ ] 备份文件完整性验证通过
- [ ] 恢复演练通过
- [ ] RTO < 30 分钟
- [ ] RPO < 24 小时

## 11. 文档验证

- [ ] 部署文档完整
- [ ] 运维手册完整
- [ ] API 文档完整
- [ ] 用户手册完整
- [ ] 灾难恢复手册完整
