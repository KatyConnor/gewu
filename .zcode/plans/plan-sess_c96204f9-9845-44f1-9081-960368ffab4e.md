# 预算体系重构实施计划（方案A + 配套项，已经交互审阅确认）

## 1. BudgetController 时间降级为告警（语义重构）
- `check()`：BLOCK 仅由 Token 超限 / 轮次超限触发；时间维度不再阻断
- DEGRADE/ALERT 信号保留（取 token/time 最大值，供模型降级决策）
- 新增 `renewTimeBudget(ctx)`：时间满额且 Token/轮次健康时滚动续期（elapsed + max(base/2, 30s)），持续健康推进的任务永不因墙钟被杀

## 2. 执行器接入（ReactAgentExecutor）
- 流式轮次头：先滚动续期（续期时发 budget_warning 事件「时间预算已满，已自动续期，任务继续推进」），再 shouldStop（仅 Token/轮次熔断，已带 done）
- 流式 Token 记账：每轮结束按估算（prompt+reasoning+content 字符量）调 consume——Token 预算在流式模式真正生效（当前恒为 0 从不阻断），轮次计数同步
- 同步路径：循环头同样先续期再检查
- 账本准确性：budget_stopped 标记——熔断的运行 recordFailure 替代 recordSuccess、跳过经验沉淀（部分内容不污染记忆）

## 3. 预算告警事件补齐（前端可见）
- 70%/90% ALERT/DEGRADE 与续期均发 budget_warning 事件（当前常量是死代码）
- chat.ts 增加 onBudgetWarning 回调；ChatPage toast 非阻塞提示剩余预算

## 4. Token 预算配置化
- AgentEngineProperties.Budget 增 tokenBudget（默认 81920，替代 defaultMaxTokens×10 硬推导）
