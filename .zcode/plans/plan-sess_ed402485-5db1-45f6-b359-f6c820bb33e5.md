## Batch 2 — P1 安全×5

### 2.1 校验器接线（复活 SandboxValidator）
- `SandboxConstants.ALLOWED_IMAGE_PREFIXES` 增补 `gewu/dev-` 与 `gewu/sandbox:`（现白名单缺前者，直接接线会误拒 dev 沙箱），白名单改为可配置 `gewu.sandbox.security.allowed-image-prefixes`（兼容 env 覆盖场景）
- `SandboxService.createSandbox`（L44-91）在镜像空判后调用 `sandboxValidator.validateImage(image)` + 服务端资源上限强制（cpu≤8 核/mem≤16G/disk≤50G/timeout≤86400，以 SandboxConstants 为准，严于 DTO @Max）
- `executeCode:170` timeout 钳制至 MAX_TIMEOUT_SECONDS
- 测试：`SandboxServiceValidationTest`（非法镜像拒/gewu/dev-base 通过/超限拒）

### 2.2 审计补全（统一写入方 + result + FILE_ACCESS + SM3 链）
- `logAudit:277-295` 增加重载带 result 参数；现有成功路径调用点补 "SUCCESS"，create/start/stop/destroy/executeCode 的 catch 路径补记 "FAIL"（修复 result 恒 SUCCESS）
- `SandboxFileController` 5 端点：注入 SandboxService，记 `FILE_ACCESS` 审计（WRITE/READ/UPLOAD/DOWNLOAD/DELETE + 路径）并 touch lastUsedAt（镜像 execCommand:147-148 模式）——同时解决"文件操作不计入活跃"
- **SM3 哈希链**：insert 前计算 `logHash = SM3Util.hashHex(prevLogHash|sandboxId|action|userId|details|result|timestamp)`（`gewu-common/.../crypto/SM3Util.hashHex:28` 现成可用；gewu-sandbox 已依赖 gewu-common）；prev 取最近一条；JVM 级 ReentrantLock 保证单实例链连续（多实例分叉风险注释注明，沙箱服务当前单实例部署）
- SandboxAuditService 的 log* 方法标 @Deprecated 注释（统一由 SandboxService.logAudit 写入，避免双写破坏链）；@EnableAsync 不再需要
- 测试：`AuditChainTest`（mock mapper 验证链式传递与 FAIL 记录）

### 2.3 方法级鉴权生效
- `SandboxSecurityConfig` 加 `@EnableMethodSecurity`；InternalApiKeyFilter（L98-99）认证成功时授予 `sandbox:manage` 权限（现为空 List）→ `@PreAuthorize`（exec/executeCode）真实生效且 internal 调用可过

### 2.4 密钥治理
- 两个 yml 的 `${GEWU_INTERNAL_API_KEY:gewu-dev-internal-key-change-me}` 弱默认移除（→ `${GEWU_INTERNAL_API_KEY:}`）；`SandboxSecurityConfig` 加 @PostConstruct：**prod profile** 密钥为空或等于历史默认串 → 启动失败；dev 为空仅 WARN
- `.env.example` 补 `GEWU_INTERNAL_API_KEY=` 条目；crypto api-key-secret 三处默认值不一致问题：prod 检测到已知弱默认打 WARN（代码侧 @PostConstruct 已强制 32-hex，不宜 fail-fast 以免破坏既有部署）

### 2.5 NetworkPolicy 选择器修正
- `deploy/k8s/network-policy.yaml:7-9` podSelector.matchLabels 改为 helm 实际标签 `app.kubernetes.io/name: gewu-platform` + `app.kubernetes.io/component: sandbox`（与 templates/sandbox.yaml L20-23 对齐）；无集群环境，标注"未验证"
