# 「我的智能体」页四按钮功能补齐方案

## 根因（已排查确认）

`gewu-web/src/components/pages/MyAgentsPage.tsx` 的「创建智能体」(L32)、「配置」(L60)、「日志」(L61)、「暂停/运行」(L62) 四个按钮均未绑定 onClick，是纯 UI 壳子。

## 方案决策

- **配置/创建**：把 AgentManagePage 已有的编辑弹窗抽取为共用组件，两页复用。
- **暂停/运行 = 真暂停**：后端加校验，暂停的智能体拒绝新对话（后端 `UpdateAgentCommand` 全字段可选、`updateAgent` 已处理 status，切换本身零新增接口）。
- **日志 = 页内右侧抽屉**：数据源用后端现成的执行记录接口（`GET /api/v1/agents/executions/agent/{agentId}`，每次对话经 `AgentExecutionEngine` 真实落库，非空壳）。

## Part 1 编辑弹窗抽取 + 创建/配置接线（前端 3 文件）

1. **新建 `gewu-web/src/components/pages/AgentEditModal.tsx`**
   - Props：`{ visible: boolean; editingAgent: AgentDTO | null; onClose: () => void; onSaved: () => void }`
   - 从 AgentManagePage 迁入：6 个表单字段 + saving + allSkills/agentSkillIds 状态、resetForm、handleToggleSkill（技能挂载/卸载）、handleSave（成功后 toast + onSaved + onClose）、弹窗 JSX（原 L272-309）
   - useEffect 监听 `visible/editingAgent`：打开时回填表单并加载技能库与已挂载技能；新建时重置
2. **改 `AgentManagePage.tsx`**：删迁走的表单状态与函数（L33-46 部分、L64-130），header 创建按钮与菜单「编辑配置」改为 `setEditingAgent(...); setShowModal(true)`，渲染 `<AgentEditModal onSaved={loadAgents} />`
3. **改 `MyAgentsPage.tsx`**：「创建智能体」→ 打开弹窗（editingAgent=null）；「配置」→ `setEditingAgent(agent)` + 打开；onSaved → `loadAgents()` 刷新卡片

## Part 2 暂停/运行（真暂停，前端 + 后端）

后端（3 文件）：
1. `gewu-common/.../result/ResultCode.java`（L69-74 旁）新增 `AGENT_PAUSED(14007, "智能体已暂停，请先恢复运行")`
2. `gewu-application/.../AgentExecutionEngine.java` `loadAgent`（:349-358）：`status==0` → 抛 AGENT_PAUSED（覆盖 legacy 同步/流式两条链路，AiChatController :869/:925）
3. 同文件 `beginExecutionRecord`（wenshi 链路入口，AiChatController :154/:844 调用）：agent 存在且 status==0 时抛 AGENT_PAUSED（agent 不存在保持原行为不新增抛错，最小侵入）
4. 新增单测 `gewu-application/src/test/.../agent/AgentExecutionEnginePauseTest.java`（对齐现有 session 测试风格）：status=0 抛错、status=1 通过、无 agent 不拦截

前端：
5. `MyAgentsPage.tsx`：暂停/运行按钮 → `updateAgent(agentId, { status: isRunning ? 0 : 1 })`（接口已支持，仅需传 status）；成功 toast「已暂停/已恢复运行」+ 本地更新该卡片状态；按卡片加 loading 态防连点，失败 toast

## Part 3 日志抽屉（前端为主 + 后端安全加固）

后端（1 文件）：
1. `AgentExecutionService.java` `listExecutions`（:104-115，当前无鉴权、任何人可查任意智能体日志——顺手按 CR L3 加固）：注入 AgentMapper，校验 agent 存在 + 当前用户为创建者（ADMIN 旁路照抄 AgentService.getAgent :83-89 写法），否则 FORBIDDEN

前端（3 文件）：
2. `gewu-web/src/lib/agent.ts` 新增 `AgentExecutionDTO`（executionId/sessionId/status/input/output/errorMessage/tokensUsed/startedAt/completedAt/durationMs）与 `listAgentExecutions(agentId, page, size)`（unwrap 范式）
3. **新建 `gewu-web/src/components/pages/AgentLogsDrawer.tsx`**
   - 抽屉骨架同 AgentManagePage 详情抽屉（fixed inset-0 + justify-end + max-w-lg glass-dark）
   - 执行记录行：状态图标+徽章（成功/失败/运行中）、开始时间（秒/毫秒兼容）、耗时、tokens；点击行展开输入/输出或错误详情（font-mono 深色块），展开详情内提供「打开会话」（hash `#/chat?sessionId=...` + setPage('chat')，ChatPage 已支持解析）
   - 简易分页条（RequirementsPage :377-398 模式）、加载态、空态「暂无执行记录」、失败 toast
4. `MyAgentsPage.tsx`：「日志」→ `setLogsAgent(agent)` 打开抽屉
