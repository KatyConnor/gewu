## 工作包一：执行链完整性与双引擎收敛（P0 + 衍生遗留，先行）

### 1.1 executeStream() 模型路由补齐（衍生遗留-1）
- 修改 `ReactAgentExecutor.java`：将 `resolveProviderAndModel()` 与模型选择逻辑提取为 `execute()`/`executeStream()` 共用路径，流式路径接入 ModelSelector 路由（复杂度/预算/隐私）
- 验收：流式与非流式产出相同的 provider/model 决策；现有测试回归通过

### 1.2 cancelExecution 状态快照（衍生遗留-2）
- 修改 `OrchestrationService.cancelExecution()`（当前仅置 CANCELLED 状态）：取消前从 VersionedContext 提取最终变量版本快照 + 已完成节点输出摘要，写入 execution 记录（复用 artifact 字段或新增 snapshot JSON 列）
- 验收：取消后 `getExecution` 可返回取消时刻的上下文快照

### 1.3 P0-2 双引擎收敛
- 读取 `AiChatController` 四个方法（chatViaWenshi/chatViaLegacy/chatStreamViaWenshi/chatStreamViaLegacy，行 276-359+），逐项对齐 wenshi 路径缺失能力：文件事件、模型列表解析、会话持久化、累积 content、SSE 事件格式
- 差距修复后：`application.yml` 将 `gewu.wenshi.routing.chat/stream` 默认值 `legacy` → `wenshi`，保留 legacy 作为降级配置
- 验收：默认配置下对话走 ReactAgentExecutor 全链路（安全五层/记忆/路由/统计），行为与 legacy 对等

## 工作包二：治理与评测管线闭环（P2-5/P2-8/P2-10）

### 2.1 P2-5 PolicyService 落地
- 新建 Flyway 迁移 `V30__governance_policy.sql`：`governance_policy` 表（scenario/rule_json/version/active/created_at）
- 新建 `gewu-application/.../governance/DbPolicyServiceAdapter.java`：实现 PolicyService SPI（getActivePolicy/checkPolicy/rollbackPolicy），启动时预热缓存
- 新建 `PolicyController.java`（`/api/v1/policies`）：CRUD + 激活/回滚端点
- 种子数据：至少 `model_routing` / `tool_permission` / `hitl_threshold` 三个场景默认策略
- 验收：AutoConfiguration 中 stub 被真实 Bean 替换；策略变更后 checkPolicy 生效

### 2.2 P2-10 FourPhasePipeline 接入执行器
- 修改 `AutonomousExecutor.runWithReflection()`：目标完成（verifyGoal 之后）调用 `FourPhasePipeline.execute()` 走 execute→evaluate→govern→audit 四阶段，govern 阶段消费 2.1 的 PolicyService
- 修改 `OrchestrationService`：编排执行完成回调同样过四阶段管线（audit 阶段写审计链）
- 验收：一次编排执行产生四阶段记录；audit 阶段产物可在 audit-chain API 查询

### 2.3 P2-8 LlmJudge/SPC 评测管线
- 新建 `gewu-application/.../evaluation/EvaluationService.java`：按采样率对完成执行调用 `LlmJudge.evaluate()`（锚点用例+维度评分），结果写 evaluation 记录表 + `MetricService.recordMetric`
- 接入 `SPCDegradationDetector`：定时任务（`@Scheduled` 每小时）对近期评分序列做 SPC 检测，degraded 时告警日志 + 指标上报
- 新建 `EvaluationController.java`（`/api/v1/evaluations`）：查询评测结果/劣化报告/手动触发评测
- 验收：完成 N 次执行后可查询 LlmJudge 评分；人工压低评分序列可触发 SPC degraded 报告
