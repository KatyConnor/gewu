## 1. 背景与问题

agents.md 规范的核心语义之一是**就近优先**：monorepo 各子目录可放自己的 AGENTS.md，"距被编辑文件最近者胜"。格物当前只装载**会话根**（项目仓库根）的入口文件——模型在 `packages/foo/` 下工作时，`packages/foo/AGENTS.md` 不会生效，monorepo 团队的子项目约定丢失。

补齐该语义的前置问题是：**"当前工作子目录"从何得知**。会话不绑定 cwd（文件工具全库可访问），引擎没有"当前目录"概念。

## 2. 方案对比与选型

| 方案 | 语义 | 代价 | 取舍 |
|---|---|---|---|
| A. 会话绑定 cwd：会话创建时声明子目录，文件工具收窄到该子树 | 强约束，天然就近 | 会话模型改动大；跨包工作需多会话；与既有"目录即工作区"语义冲突 | 否 |
| **B. 工具访问感知（惰性就近）**：文件工具读写某子树文件时，向上探测入口文件，命中则**附加进当次工具结果** | 与 Claude Code 子目录 CLAUDE.md 惰性加载同构；零配置、零会话改动 | 指令进入的是工具结果段而非 system prompt；跨轮可能重复 | **采用** |
| C. 独立查询工具（entry.nearest(path)） | 模型自主控制 | 依赖模型主动性，覆盖不稳 | 否（可作 B 的补充后续加） |

## 3. 发现算法（纯函数，gewu-common）

`NestedEntryFinder.find(root, targetPath, probe)`：

1. 取目标文件所在目录 `dir = dirname(targetPath)`；
2. 自 `dir` 起**向上逐层**探测至会话根（**不含根**——根文件已随 system prompt 注入，勿重复）：
   每层按 `GEWU.md` → `AGENTS.md` 顺序探测（同层 GEWU 优先，规则与 56 §5.1 一致），命中即停；
3. probe 回调由运行时提供（平台=沙箱 readFile 探测，桌面=本地 FS），返回内容或 null；
4. 返回命中文件（相对目录 + 内容），未命中返回 null。

路径安全：逐层拼接前做规范化，拒绝越出会话根；探测本身只读。

## 4. 触发与注入（引擎接线）

- **位置**：`ReactAgentExecutor.executeFileTool`（:1096）——`read_file`/`write_file`/`edit_file` **成功后**追加检查（`list_dir` 不触发）；
- **附加段形状**（追加在工具输出尾部）：

  ```
  \n\n---\n## 子目录调度指令（packages/foo/）\n<内容>
  ```

- **去重**：`ToolContext` 增 `nestedEntriesServed`（`Set<String>` 相对目录集合）——同一次任务内同一子目录只附加一次；跨轮允许再次附加（每轮首触注入一次，成本上限可控，见 §5），文档如实声明；
- **单文件上限**：16KB，超限截断并标注。

## 5. 边界与成本（如实声明）

1. 指令在**工具结果**而非 system prompt——模型注意力弱于 system 段，属已知取舍（对齐 Claude Code 同机制）；
2. 跨轮重复注入：同一子目录每轮首触会再附加一次；上下文成本 ≤ 16KB/轮·子目录， monorepo 深工作场景可接受；
3. 仅项目层：全局层（用户级）不参与嵌套；子目录文件**不做版本裁决**（就近即胜），与根文件是**叠加**关系（根已入 system，子目录补差异）；
4. 大仓库向上探测层级 = 目标深度，每层一次沙箱探测调用——平台端探测走沙箱 HTTP（有毫秒级开销），必要时可在候选层短路（首层命中即停已是常态）。

## 6. 安全

- 子目录文件来源为 Git 仓库内容——信任定位同 56 §8.3"项目级=仓库自带"（来源标注入附加段、审计可查、平台红线门禁独立执行）；
- 密钥扫描：附加前过 `SecretScanUtil`，命中则以一行警示替代内容（不注入密钥，也不完全吞掉信号）。

## 7. 实施拆解与工作量

| 步骤 | 内容 | 估时 |
|---|---|---|
| 1 | `NestedEntryFinder`（gewu-common 纯函数）+ 表驱动单测 | 0.5d |
| 2 | 引擎接线：ToolContext 集合 + executeFileTool 三案后置检查 + 输出附加 | 0.5d |
| 3 | 测试：finder 单测 + 引擎侧 monorepo 假仓库用例（read 触发/根不触发/GEWU 优先/去重/截断） | 0.5d |

合计 1~1.5d；平台/桌面零额外改动（接线在引擎通用层，两端自动生效）。

## 8. 验收口径

1. 假仓库 `packages/foo/AGENTS.md` 声明"测试命令: pytest -q"→ 智能体 `read_file packages/foo/x.java` 后该约定出现在工具结果；
2. `read_file README.md`（根）不触发；
3. 同目录 `GEWU.md` 与 `AGENTS.md` 并存 → GEWU 胜；
4. 同轮二次读同子目录 → 不重复附加；
5. 16KB 截断生效。
