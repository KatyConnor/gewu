# 格物平台用户手册

> AI 智能体协作平台使用指南

## 1. 快速开始

### 1.1 访问平台

- 开发环境: http://localhost:3000
- 生产环境: https://gewu.com

### 1.2 注册账号

1. 访问登录页面
2. 点击"立即注册"
3. 填写用户名、邮箱、密码
4. 点击"注册"按钮

### 1.3 登录系统

1. 输入用户名和密码
2. 点击"登录"按钮
3. 系统自动跳转到首页

| Enter | 发送消息 |
| Shift+Enter | 换行 |

| Ctrl+/ | 切换侧边栏 |
| Ctrl+\ | 终端面板 |

## 4. 常见问题

### 4.1 忘记密码

1. 点击登录页面的"忘记密码"
2. 输入注册邮箱
3. 查看邮件并重置密码

### 4.2 会话丢失

- 检查网络连接
- 刷新页面
- 联系管理员

### 4.3 性能问题

- 清除浏览器缓存
- 检查网络带宽
- 联系运维团队
