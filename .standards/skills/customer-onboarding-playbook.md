# 技能模块：customer_onboarding_playbook

> 新客交付五段式：范围确认→实施计划→分阶段培训→TTV 追踪→验收移交。范围蔓延走变更单，里程碑延误超期升级。

## 1. 技能描述

本技能负责新客户从合同签订到运营移交的完整交付过程管理。方法论核心：**实施计划五段式**（范围确认/计划制定/分阶段培训/TTV 追踪/验收移交）、**TTV 优先**（首次价值时间——比"按期上线"更重要的北极星是客户尽早获得第一个可感知价值）、**验收标准前置**（每个里程碑在启动前定义验收标准，杜绝"做完了客户不认"）。范围纪律：任何超出合同的交付内容走变更单（02 确认），不免费扩范围。

## 2. 触发条件

- 输入包含「onboarding」「实施计划」「客户验收」「TTV」「新客交付」等关键词
- 存在 02 商务移交的合同与交付范围
- 里程碑延误或客户验收争议处理

## 3. 执行步骤

1. **范围确认**：合同交付范围逐条转化为可验证交付物清单；边界外需求登记变更单。
2. **实施计划**：里程碑划分（每段含验收标准/负责人/时间），识别客户侧依赖（数据/环境/人员）。
3. **分阶段培训**：管理员/关键用户/普通用户分层培训，配验收前操作考核。
4. **TTV 追踪**：定义该客户的首个价值场景（业务动作完成），追踪达成时间；偏差分析并干预。
5. **验收移交**：验收单签署 → 运营移交单（健康度基线/联系人地图/已知风险）→ 进入 14 号健康度运营。

## 4. 输入规范

```yaml
contract: 合同与交付范围路径
scope_items: 交付物清单（可验证）
customer_org: 组织图与关键人（决策人/管理员/终端用户）
value_first: 首个价值场景定义（TTV 目标）
timeline: 里程碑时间表
```

## 5. 输出格式

```markdown
# [客户名] Onboarding 实施计划（版本）
## 交付范围（含变更单登记位）
## 里程碑表（验收标准/负责人/时间/依赖）
## 培训计划（分层/考核）
## TTV 追踪（目标/实际/偏差干预）
## 验收单 + 运营移交单（健康度基线/联系人地图/已知风险）
```

## 6. 质量标准

- 里程碑 100% 有前置验收标准（无标准不启动）
- TTV 100% 定义并追踪（禁止只按期上线不看价值）
- 范围外需求 100% 走变更单（零免费扩范围）
- 移交单 100% 含健康度基线与联系人地图

## 7. 风险控制

| 规则 | 内容 |
|------|------|
| RISK-01 | 范围蔓延（未走变更单的扩需求）立即冻结并登记 |
| RISK-02 | 里程碑延误超 2 周升级 10/02（客户侧依赖阻塞单列） |
| RISK-03 | 验收争议（标准歧义）回溯前置验收单，无单则复盘流程 |
| RISK-04 | TTV 偏差超 50% 未干预判为交付失焦 |
| RISK-05 | 移交后前 30 天健康度无人接管（移交断档） |

## 8. 跨角色协作接口

```yaml
上游角色:
  - 02-产品经理: 提供合同范围与商务移交
  - 12-技术写作: 提供客户版培训与交付文档

  - 14-本角色健康度技能: 接收运营移交（健康度基线）
  - 10-PM: 接收里程碑延误升级
  - 02-产品经理: 接收变更单裁决
传递字段: [实施计划, 验收单, TTV报告, 移交单]
```
