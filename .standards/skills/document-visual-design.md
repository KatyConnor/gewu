# 技能模块：document_visual_design

> 文档版式设计规范：@page 三件套 + 分页容器 + 渲染三查。内容结构归 TPL 模板，视觉规格归本技能——本技能是"文档的 UI 层"。

## 1. 技能描述

本技能承载交付级文档的**版式与视觉设计**能力（区别于 11 号卡的产品界面设计）：页面规格声明、手动分页结构、封面元素、正文版式基线（字体/行高/表格/代码块/中英混排）、渲染后三查与 QA 阈值判定。方法论来源：体系内实战教训的规则化（V1.8.15 部署手册格式事故的根因全部入律）。

## 2. 触发条件

- 输入包含「文档版式」「排版」「手册美化」「PDF 排版」「封面」「分页」等关键词
- 12 号卡产出交付级文档（手册/参考/报告）且目标媒介为 PDF/正式 HTML
- 版式异常处置（空页/溢出/越界）

## 3. 执行步骤

1. **页面规格声明**（@page 铁律）：渲染前必须显式声明 `@page { size: <宽>px <高>px; margin: 0 }`——未声明即渲染 = 版式违规（默认页尺寸切页是头号事故源）。
2. **分页结构**：每页一个固定高度容器（与 @page 尺寸一致，`overflow:hidden`），页内元素流式；**禁止**依赖 CSS page-break 单独分页（容器高度+@page 双保险）。
3. **封面规格**：tag（体系标识）/标题/副题/分隔线/元信息块/页脚线六元素；封面独占一页。
4. **正文版式基线**：正文字号 12~12.5px/行高 1.8~1.85；表头深底白字/斑马纹/边框 1px；行内代码等宽字体+浅底；提示框（左侧 3px 主题色边+浅底）；章节头（编号+标题+英文角标+底边线）。
5. **中英混排规则**：中西文之间加空格；全角标点禁与半角混用同类；代码/路径/命令一律行内代码样式（不裸排）。
6. **页码与盖章**：跳过封面与尾页；页脚居中小号灰字。
7. **渲染三查**（交付前必过）：①空页检查（逐页文本非空）②首页元素检查（封面脚注/关键元素在 p1）③越界块检查（块边界不出页面矩形）。
8. **QA 阈值判定**：pdf_qa 警告数 ≤3 为正常；**>3 即版式异常**（V1.8.15 实证：乱版=7 警告，正常=3），修完再交付。

## 4. 输入规范

```yaml
content: 文档内容源（markdown/html）
doc_type: 手册 | 参考 | 报告 | 教程
medium: pdf | html
page_spec: {width: 720, height: 1020}
palette: 主题色系（默认深蓝 #1c2333 / 强调 #1f6feb）
```

## 5. 输出格式

```markdown
# 版式交付报告
## 页面规格（@page 声明原文）
## 分页结构（页序 × 内容块映射）
## 渲染三查结果（空页/首页元素/越界块）
## QA 警告数与判定（≤3 通过）
## 复用样式核对记录（类名覆盖清单）
```

## 6. 质量标准

- @page 声明 100% 在场（渲染前）
- 复用他人样式 100% 先做类名覆盖核对（grep 类名存在性）——未核对禁止使用
- 空页 100% 消除；越界块 100% 为 0
- pdf_qa 警告 100% ≤3 才交付
- 行内代码 100% 走 code 样式（裸排=违规）

## 7. 风险控制

| 规则 | 内容 |
|------|------|
| RISK-01 | 未声明 @page 即渲染 = 违规（头号事故源，V1.8.15 实证） |
| RISK-02 | 复用样式未核对类名存在性（幽灵类裸奔，V1.8.15 实证 cov-meta/tip） |
| RISK-03 | 空页/溢出页未消除即交付 |
| RISK-04 | QA 警告 >3 未修即交付 |
| RISK-05 | 代码/命令裸排（不用行内代码样式） |
