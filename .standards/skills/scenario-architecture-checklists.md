# 技能模块：scenario_architecture_checklists

> 三张场景架构检查清单的实体定义（分布式/云原生/AI 工程化）——闭环角色卡触发规则的三处清单承诺。每项带客观通过判据，检查结果留痕。

## 1. 技能描述

本技能是角色卡 03 §3.2 自动激活规则的清单实体：命中「微服务/分布式」叠加**分布式专项检查**，命中「云原生/K8s/Serverless」叠加**云原生合规检查**，命中「大模型/RAG/Agent」叠加 **AI 工程化检查**。三清单各 12 项，每项含通过判据（客观可验证）；未通过项进入整改清单或登记豁免（豁免须记录理由与责任人，不可静默跳过）；检查结果写入 AETC 留痕。

## 2. 触发条件

- 角色 03 激活且场景命中三清单任一触发词
- 架构评审/准出前的专项复核
- 整改项复验

## 3. 执行步骤

1. **清单匹配**：按场景命中加载对应清单（可叠加，多场景全量）。
2. **逐项检查**：按通过判据核验当前架构设计/拓扑/配置，标记通过/未通过/不适用。
3. **不适用项登记**：记"不适用"必须附理由（静默跳过 = 检查无效）。
4. **未通过项处置**：进整改清单（责任方/期限）或登记豁免（理由+会签）。
5. **留痕**：检查报告（含三态分布与整改/豁免登记）写入 AETC。

## 4. 输入规范

```yaml
checklist: distributed | cloudnative | ai-engineering（可多选）
design_doc: 架构设计文档路径（含拓扑与技术栈）
deployment: 部署形态（单机房/多AZ/云上/混合）
ai_form: AI 应用形态（对话/RAG/Agent 工具链，仅 AI 清单需要）
```

## 5. 输出格式

```markdown
# 专项架构检查报告（清单名/日期）
## 检查总览（通过/未通过/不适用 三态计数）
## 未通过项 → 整改清单（责任方/期限）
## 豁免登记（理由/会签/有效期）
## 留痕记录（AETC 编号）
```

## 6. 质量标准

- 命中触发词的场景 100% 执行对应清单（触发即检查）
- "不适用" 100% 附理由（零静默跳过）
- 豁免 100% 有会签与有效期（不可永久豁免）
- 检查报告 100% 留痕

## 7. 三张清单（各 12 项，含通过判据）

### 7.1 分布式专项检查

| # | 检查项 | 通过判据 |
|---|--------|----------|
| D1 | 一致性口径显式化 | 每个跨服务数据流已声明强一致/最终一致，最终一致路径有补偿设计 |
| D2 | 幂等性 | 所有写接口有幂等键或去重窗口定义，重复请求结果不变 |
| D3 | 超时与重试预算 | 每条同步链路的超时层级递增（上游>下游总和），重试有上限+退避 |
| D4 | 雪崩防线 | 依赖链上每个远程调用有熔断/限流/隔离三者至少其一 |
| D5 | 数据分片与热点 | 分片键已选型，热点键有打散或本地缓存方案 |
| D6 | 时钟偏序 | 跨节点排序不依赖本地时钟（逻辑时钟/中心版本） |
| D7 | 脑裂仲裁 | 有主备/选主的组件已定义 quorum 或仲裁方 |
| D8 | 新旧并存兼容 | 发布窗口内新旧版本可互操作（灰度兼容层/双写/版本字段） |
| D9 | 失败域隔离 | 单组件故障的影响面已圈定，无单点跨全链路 |
| D10 | 容量水位 | 峰值容量×余量系数（≥1.5）有测算依据 |
| D11 | 跨 AZ 延迟预算 | 跨机房调用列入链路延迟预算，同步链路无跨 AZ 强依赖（或已声明代价） |
| D12 | 故障演练项 | 本设计的 Top3 故障场景已定义演练方法（对应角色 09） |

### 7.2 云原生合规检查

| # | 检查项 | 通过判据 |
|---|--------|----------|
| C1 | 无状态化 | 应用实例不落本地状态（会话/文件外置到缓存/对象存储） |
| C2 | 配置与密钥分离 | 配置走环境/ConfigMap；密钥不进镜像与代码库 |
| C3 | 健康探针三件套 | liveness/readiness/startup 齐备且语义正确（readiness 挡流量非重启） |
| C4 | 优雅停机 | SIGTERM 处理含连接排空， terminationGracePeriod 覆盖最长请求 |
| C5 | 资源边界 | requests/limits 已设置且基于实测（非拍脑袋） |
| C6 | 水平伸缩依据 | HPA/VPA 伸缩指标与业务负载相关性已论证 |
| C7 | 镜像供应链 | 最小基座镜像+漏洞扫描+签名校验（digest 固定） |
| C8 | 可观测三信号 | 日志/指标/trace 三信号接入点已在架构图标注 |
| C9 | 网络默认拒绝 | NetworkPolicy/安全组默认拒绝，白名单显式开放 |
| C10 | 有损降级 | 过载路径有降级预案（非直接 500），降级开关已定义 |
| C11 | 配置漂移检测 | 声明式配置有漂移检测手段（GitOps 对账或等价） |
| C12 | 部署不可变 | 运行时配置变更走重新部署，禁止在线热改镜像内容 |

### 7.3 AI 工程化检查

| # | 检查项 | 通过判据 |
|---|--------|----------|
| A1 | 评测集先行 | 上线前有 evals 基线集（输入/期望输出/评分方法），无评测不发布 |
| A2 | 提示词版本化 | 提示词纳入版本管理，变更有回归评测（对照 A1 基线） |
| A3 | 结构化输出校验 | 模型输出的 schema 校验+失败重试/降级路径已定义 |
| A4 | 幻觉防线 | 事实类回答有引用锚定或拒答策略（无依据不编造） |
| A5 | 上下文预算 | prompt+检索内容的 token 预算已测算，超限截断策略已定义 |
| A6 | 检索质量 | RAG 路径有召回率/排序质量的度量指标与基线 |
| A7 | 成本与延迟预算 | 单请求 token 成本与 P95 延迟预算已核算（超预算告警） |
| A8 | 模型降级路径 | 主模型不可用的 fallback（备模型/规则兜底）已定义 |
| A9 | 安全护栏 | 注入攻击/越权指令/敏感数据外泄三类防线已设计（协同角色 05/07） |
| A10 | 数据隔离 | 多租户数据隔离明确，PII 不入 prompt（或脱敏后进入） |
| A11 | 全链路可观测 | trace 含模型版本/提示词版本/成本维度（协同角色 08 口径） |
| A12 | 人在回路 | 高风险决策（资金/合规/不可逆动作）有人工确认节点 |

## 8. 跨角色协作接口

```yaml
上游角色:
  - 03-本角色system-design-doc: 提供架构设计输入
  - 08-数据专家: 提供 AI 路径度量口径（A6/A11）

  - 04-全栈开发: 接收整改清单的实现项
  - 09-SRE专家: 接收 D12/C 类运维协同项
  - 05/07-安全合规: 接收 A9/C2/C9 协同项
  - AETC留痕域: 接收检查报告留痕
传递字段: [检查报告, 整改清单, 豁免登记]
```
