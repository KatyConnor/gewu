# 浏览器 E2E 黑盒验证（browser-e2e-validation）

*本文件版本：V1.0 | 更新日期：2026-10-08 | 创建依据：rev-spec-utss-v1.2 REV-004（外源接测 S4-S6 执行协议）*

> 隶属：UTSS V1.2 外源接测模式（§三·B S5-S6）执行层技能 · 角色卡 06 号主绑定。
> 工具链：agent-browser（浏览器自动化：导航/点击/输入/快照）+ VLM（截图语义判定）。

## 1. 技能描述

在他人提交分支构建部署的**远程测试环境**上，经外联地址登录后执行黑盒 E2E 验证：
页面流功能断言 + 视觉验证三模式 + 结果归档。产出可直接进 T-E2E-01 报告与 AEGIS RC 单。

本技能是**执行协议**（怎么跑），用例从哪来归 test-case-generation §9.6，
部署怎么配归 cicd-pipeline-config，基线容差标准归 11 号卡 CHK-30/31。

## 2. 触发条件

- UTSS 外源接测模式（§三·B）推进到 S5/S6
- 或任务短语含：外联验证/登录测试/黑盒 E2E/远程环境页面验证
- 前置：S4 环境冒烟三查已过（服务可达/关键路由 200/构建版本号正确）

## 3. 凭据安全红线（S5 · 违反任一即本轮 FAIL）

| # | 红线 | 执行方式 |
|---|---|---|
| C1 | **禁入留痕**——凭据不写入任何 AETC trace/检查点文件 | 凭据从环境变量（`TEST_ENV_USER/PASS`）或凭据文件（gitignore 外）读取，会话内内存持有 |
| C2 | **禁入报告与用例文档**——T-E2E-01/用例/日志中凭据零出现 | 报告模板硬约束；输出前对截图做脱敏检查（密码框掩码确认） |
| C3 | **禁入命令回显**——不在命令行明文传参 | 经 stdin/环境变量注入 agent-browser 凭据参数 |

## 4. 执行步骤（S5→S6）

1. **环境冒烟先行**（两查不过即停——环境问题≠产品缺陷，如实标 BLOCKED-environment）：
   - HTTP 可达（状态码 200/3xx 重定向到登录页）
   - 登录页关键元素在场（表单/输入框/提交钮——快照断言）
2. **登录会话建立**：填入凭据→提交→断言登录成功标志（用户名回显/登出按钮/仪表盘路由）
   - 登录失败处理：凭据错→BLOCKED-environment；登录页 500→环境级缺陷候选
3. **功能流断言**（按 S3 用例集逐条）：
   - 页面流：导航→关键元素在场→交互（点击/输入）→结果断言（DOM/路由/提示）
   - 业务闭环：按用例 GWT 的 Then 写断言脚本（agent-browser snapshot→元素选择器/文本匹配）
   - 失败即录：截图+URL+时间戳+用例号→缺陷候选（进 §7）
4. **视觉验证**（三模式自动选择）：
   - **首跑（无基线）**：全关键页截图→建基线库（命名：`页面ID-viewport-基线版本.png`，落 `tests/qa/baselines/`，进 AETC 留痕）→本模式结论=基线登记+VLM 语义走查（明显错乱：文字重叠/按钮截断/布局塌陷）
   - **回归（有基线）**：借 UTSS §9.4 对比三档（布局断言优先/像素 diff/组件级）+防抖三件套——容差判据用 11 号卡 CHK-30/31
   - **语义判定**：VLM 看截图答"该页面是否达可用状态"（用于无明确期望的探索式用例——结论标 low-confidence，不当准出门禁项）
5. **执行记录归档**：每用例一条（用例号/步骤/断言结果/截图路径/耗时/环境指纹【URL+构建版本号】）

## 5. 输入规范

| 输入 | 来源 | 约束 |
|---|---|---|
| 外联地址+凭据 | 环境变量/凭据文件 | C1-C3 红线 |
| 用例集 | S3（§9.6 派生） | source 标注完备 |
| 视觉基线 | tests/qa/baselines/ | 首跑自建，版本化 |
| 容差标准 | 11 号卡 CHK-30/31 | 像素级关键页/布局级常规页/语义级内容页 |

## 6. 输出格式（T-E2E-01 素材）

```
### E2E 执行记录（S6）
- 环境指纹：{外联地址脱敏} | 构建版本 {version} | 分支 {branch}@{commit 8位}
- 用例执行：{总数/通过/失败/阻塞} 矩阵逐条（用例号/结果/耗时）
- 视觉验证：{模式} | 基线版本 {v} | 结论（首跑=基线已建走查通过/回归=差异 N 处）
- 缺陷清单：{RC 单号/严重级/复现步骤/截图}
- 凭据检查：✓ 留痕/报告/命令回显零出现（自查声明）
```

## 7. 缺陷流入（→AEGIS）

- 环境级（登录 500/服务不可达）：BLOCKED-environment，不开 RC 单，反馈部署侧（cicd）
- 产品级（断言失败/视觉超容差）：开 AEGIS RC 单——预期依据写入 expected 字段
  （模糊档用例的预期=合理用户预期，注明 source=code-analysis/exploratory）
- 视觉回归差异未超容差：记录 observation 不开单，进报告"观察项"段

## 8. 质量标准

- 断言可复现：任何 FAIL 结论附复现步骤+截图+环境指纹
- 不伪造：网络抖动类失败重跑 2 次仍失败才定 FAIL（防抖对齐 §9.4）
- 视觉结论分级：像素/布局级=可门禁；语义级=low-confidence 不进门禁
- 用例覆盖率对照：S3 用例 100% 有执行记录（BLOCKED 也记录）

## 9. 风险控制

- 环境漂移：每轮执行前校验构建版本号（与 S4 部署版本一致才执行）
- 会话失效：登录态丢失自动重登（最多 2 次），仍失败标 BLOCKED-environment
- 凭据泄露自检：全部产出物生成后 grep 凭据字面量（命中即销毁重做+红线 FAIL 上报）
