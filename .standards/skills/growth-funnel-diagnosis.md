# 技能模块：growth_funnel_diagnosis

> AARRR 全链健康度巡检与卡点定位。指标体系由 08 设计（本技能是使用层非设计层），口径治理与 08 会签。

## 1. 技能描述

本技能基于 08 数据专家交付的指标字典与看板，执行增长漏斗的诊断闭环：AARRR（获取/激活/留存/变现/推荐）逐级健康度评估 → 转化率基准比对 → 卡点定位（分群下钻）→ 假设清单产出（供实验技能承接）。附带**口径一致性巡检**：核心指标口径与字典比对，漂移项提报 08 变更。纪律：诊断结论必须附数据窗口与分群口径，禁止无口径引用。

## 2. 触发条件

- 输入包含「增长诊断」「漏斗」「AARRR」「卡点」「留存分析」「口径」等关键词
- 存在 08 产出的指标字典/看板（数据基座）
- 周期性健康度巡检或增长指标异动告警

## 3. 执行步骤

1. **基座核对**：确认指标字典版本与看板口径一致（口径巡检第一步）。
2. **AARRR 逐级评估**：每级取当前值/基准值/环比趋势，标记异常级。
3. **卡点定位**：对异常级做分群下钻（新老客/渠道/平台），定位最小卡点单元。
4. **假设产出**：每个卡点输出假设卡（现象→可能原因→可验证动作→预期指标），按影响面×可达性排序。
5. **口径巡检**：报表/口径与字典全量比对，漂移项列变更提报单（08 会签）。
6. **输出诊断报告**：卡点清单+假设清单+口径漂移清单，传递实验/分层技能与 02/08。

## 4. 输入规范

```yaml
metrics_dict: 指标字典路径与版本
dashboard: 看板数据源与窗口
benchmarks: 基准来源（历史均值/行业基准/目标值）
segments: 下钻分群维度清单
scope: 全链 | 指定级（如 activation）
```

## 5. 输出格式

```markdown
# 增长漏斗诊断报告（窗口/口径版本）
## AARRR 健康度总览（每级：当前/基准/趋势/状态）
## 卡点清单（分群下钻证据）
## 假设清单（排序：影响面×可达性）
## 口径一致性巡检（漂移项→变更提报单）
## 传递信息（02/08/实验队列）
```

## 6. 质量标准

- 诊断结论 100% 附数据窗口与分群口径
- 卡点 100% 有下钻证据（禁止"感觉转化率低"式结论）
- 假设卡 100% 含可验证动作与预期指标（可直接进实验队列）
- 口径漂移 100% 提报（未提报的口径禁止对外引用）

## 7. 风险控制

| 规则 | 内容 |
|------|------|
| RISK-01 | 无口径版本号的诊断报告无效 |
| RISK-02 | 基准缺失时禁止趋势结论（只描述现状） |
| RISK-03 | 下钻超过三层须登记口径快照（防辛普森悖误读） |
| RISK-04 | 口径漂移未提报 08 前引用旧报表判为违规 |

## 8. 跨角色协作接口

```yaml
上游角色:
  - 08-数据专家: 提供指标字典/看板/下钻数据
  - 09-SRE专家: 提供可用性数据（体验类卡点输入）

  - 02-产品经理: 接收需求级洞察提报
  - 13-本角色实验技能: 接收假设清单（实验队列）
  - 08-数据专家: 接收口径变更提报单
传递字段: [诊断报告, 卡点清单, 假设清单, 口径提报单]
```
