# 技能模块：ux_wireframe_prototyping

> 从 PRD 到可编码的界面方案：信息架构 → 任务流 → 线框 → 高保真，五态全覆盖、断点全覆盖、令牌全标注。

## 1. 技能描述

本技能将 02 产品经理的 PRD 转化为结构化界面方案。核心链路：信息架构（导航模型/层级树/命名体系）→ 任务流与状态设计（主流程深度 ≤ 3 / 五态覆盖）→ 低保真线框（栅格与区块）→ 高保真方案（令牌标注 + 组件规格）。所有视觉数值强制引用 design-tokens.json，所有方案交付前执行三重自检（启发式 / UI 禁令 / WCAG）。

## 2. 触发条件

- 输入包含「线框」「原型」「高保真」「信息架构」「界面设计」「交互设计」等关键词
- 存在明确的 PRD 或功能范围描述
- 端范围已知或可推断（桌面 / 平板 / 移动）
- 已指定令牌基线（默认 ui-design/design-tokens.json）

## 3. 执行步骤

1. **解析 PRD 与用户旅程**：提取功能模块、任务优先级、用户角色与场景。
2. **信息架构设计**：选型导航模型（层级式/平铺式/矩阵式/混合式），产出页面层级树（深度建议 ≤ 3 层），建立命名体系（用户语言对齐）。
3. **任务流设计**：绘制核心任务流（点击路径深度 ≤ 3），识别异常路径与撤销路径，显式设计五态（默认/空/加载/错误/成功）。
4. **线框产出**：按 8px 基线网格组织区块结构，覆盖断点三档（<768 / 768-1200 / >1200），标注信息密度分层。
5. **令牌选配**：建立语义令牌映射（color-primary / text-secondary / space-lg 等），全部引用现有令牌，缺口记录并走变更单（见 design-system-tokens 技能）。
6. **高保真方案**：视觉规格（配色/字阶/间距/图标）逐项标注令牌引用，产出组件规格清单（组件名、状态数、令牌引用、交互行为）。
7. **三重自检**：执行启发式 10 项（配合 usability-heuristics-review 技能）、UI 禁令 25 项（ai-antipatterns-checklist）、WCAG AA 12 项。严重度 ≥ 3 的问题修复后方可交付。
8. **交接输出**：产出设计说明 + 令牌引用表 + 组件规格清单 + 自检记录，按跨角色协作接口传递。

## 4. 输入规范

```yaml
PRD: [02 产出文档路径]
功能范围: [模块边界描述]
用户旅程: [user-journey-mapping 产出]
端范围: [">1200", "768-1200", "<768"]
令牌基线: ui-design/design-tokens.json
无障碍级别: AA
性能预算: {首屏LCP: "<2.5s", 首包: "<500KB"}
品牌约束: [可选]
```

## 6. 质量标准

- 核心任务流点击路径深度 ≤ 3，异常路径与撤销路径 100% 显式设计
- 五态（默认/空/加载/错误/成功）覆盖率 100%，禁止「正常路径 only」交付
- 断点三档全覆盖，同任务流跨断点等效性验证通过
- 视觉数值 100% 令牌化（零私有数值），冲突以 design-tokens.json 为准
- 组件规格清单完备（缺规格组件视为方案未完成）
- 核心流程 WCAG 2.2 AA 达标（正文对比度 ≥ 4.5:1，键盘可达，焦点可见）
- 触控热区 ≥ 44px（移动档），点击目标间距 ≥ 8px

## 7. 风险控制

| 规则 | 内容 |
|------|------|
| RISK-01 | 私有数值（非令牌颜色/字号/间距）出现即强制替换或走变更单 |
| RISK-02 | 空态/错误态缺失强制补设计 |
| RISK-03 | 对比度未校验的配色方案禁止交付 |
| RISK-04 | 无组件规格的高保真禁止交接 04 |
| RISK-05 | 需求变更后 24h 内同步方案与走查记录 |
| RISK-06 | 感知性能方案超 09 预算时回退（骨架屏降级为占位符） |
| RISK-07 | 移动档热区 < 44px 阻断交付 |
