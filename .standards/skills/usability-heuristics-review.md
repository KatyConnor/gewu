# 技能模块：usability_heuristics_review

> Nielsen 十启发式逐项评审 + 严重度 0-4 分级 + 问题路由：方案定稿前的最后一道体验闸，AEGIS 修复域 UI 缺陷的设计侧走查依据。

## 1. 技能描述

本技能基于 Nielsen 十大可用性启发式，对界面方案（定稿前）与实现产物（交付验收时）执行逐项走查。每个命中问题按严重度 0-4 分级，3/4 级阻断交付；问题按归属路由（需求级 → 02、实现级 → 04/AEGIS、方案级 → 11 自迭代）。与 UI-STD-001 的 ai-antipatterns-checklist（25 项）联动：本技能管「可用性」，清单管「生成质量」，两者互补不重复。

## 2. 触发条件

- 输入包含「可用性」「走查」「启发式」「UX 评审」「设计还原」等关键词
- 界面方案定稿前（强制时机：三重自检第一层）
- 实现产物交付验收（还原走查）
- AEGIS 修复域缺陷单含 UI 类走查字段
- 用户直接要求界面评审

## 3. 执行步骤

1. **确定评审对象与口径**：方案级（线框/高保真）或实现级（运行中界面）；明确核心任务流清单（作为严重度判定的任务基准）。
2. **十启发式逐项过检**：按下表逐条检查，每项记录命中/未命中/不适用 + 证据描述（截图引用或方案节点引用）。
3. **严重度分级**：每个命中问题按 0-4 定级（分级标准见 §6），核心任务流命中加权一级。
4. **问题路由**：需求级（范围/流程缺陷）→ 路由 02；实现级（还原偏差/代码缺陷）→ 路由 04 或 AEGIS（RC 单设计字段）；方案级 → 本角色自行迭代并复检。
5. **回归复检**：修复后仅复检命中项，回归结论写入交付记录。
6. **联动对账**：与 ai-antipatterns-checklist 25 项结论对账，重叠问题以更严重者为准，避免双重计数。

## 4. Nielsen 十启发式检查表

| # | 启发式 | 检查要点 | 常见命中 |
|---|--------|----------|----------|
| H1 | 系统状态可见性 | 操作反馈、异步进度、当前位置 | 提交无 loading、无进度指示 |
| H2 | 系统与真实世界匹配 | 用户语言、惯例、信息顺序 | 系统术语直出、日期格式混乱 |
| H3 | 用户控制与自由 | 撤销、重做、退出路径 | 无返回、不可取消的破坏操作 |
| H4 | 一致性与标准 | 同义同形、平台惯例 | 同类按钮不同样式、图标语义混用 |
| H5 | 错误预防 | 前置校验、二次确认 | 可预防的错误放行到提交后 |
| H6 | 识别而非回忆 | 选项可见、上下文保留 | 隐藏关键操作、跨页丢上下文 |
| H7 | 灵活与效率 | 快捷路径、批量操作 | 高频操作无快捷方式 |
| H8 | 美学与极简设计 | 信息密度、视觉噪声 | 冗余装饰挤占任务信息 |
| H9 | 错误恢复协助 | 错误信息可行动 | 「操作失败」无原因无出路 |
| H10 | 帮助与文档 | 入口、场景化指引 | 无空态引导、帮助入口缺失 |

## 6. 质量标准

**严重度分级标准（0-4）**

| 级别 | 定义 | 处置 |
|------|------|------|
| 0 | 无关紧要 | 忽略 |
| 1 | 轻微问题，用户可自行绕过 | 建议清单 |
| 2 | 明显阻碍，拖慢任务但不中断 | 建议清单（下迭代修复） |
| 3 | 阻碍任务完成，需外部帮助 | **阻断交付，修复后复检** |
| 4 | 阻断核心任务流且无出路 | **阻断交付，最高优先修复** |

- 十启发式逐项结论必填（含「不适用」的理由）
- 核心任务流命中问题严重度加权一级
- 3/4 级问题 100% 阻断并复检闭环
- 与 25 项反模式清单对账完成（重叠去重）
- 问题路由 100% 明确归属（禁止「待定」）

## 7. 风险控制

| 规则 | 内容 |
|------|------|
| RISK-01 | 评审结论只有「通过/不通过」而无逐项证据时视为未评审 |
| RISK-02 | 3/4 级问题未修复即交付，判定为 GATE 违规 |
| RISK-03 | 实现级走查偏差未分级（阻断/建议/忽略）禁止路由 |
| RISK-04 | AEGIS UI 缺陷走查结论未写入 RC 单设计字段，判定流程断裂 |
| RISK-05 | 复检只验命中项，禁止全量重跑（效率红线） |
| RISK-06 | 主观审美意见不得计入严重度（只计可用性证据） |
