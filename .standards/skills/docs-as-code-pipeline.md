# 技能模块：docs_as_code_pipeline

> 文档如代码：版本化、构建、四项门禁检查（死链/引用/术语/示例）、与发布准出并联的 CI 集成。

## 1. 技能描述

本技能负责文档工程基础设施建设：将文档资产纳入与代码同等的工程化管控。核心机制：**docs-as-code**（文档与代码同仓库、同评审流、同版本语义）、**四项管线检查**（死链检查、交叉引用校验、术语一致性扫描、示例执行验证）、**双门并联**（文档门禁与 06 测试准出同级并联，双双通过才可发布）。同时维护 TPL 模板引用映射（工程文档全量走 TPL 标准）与文档资产清单。

## 2. 触发条件

- 输入包含「文档工程」「文档站」「文档构建」「死链」「文档 CI」「开发者门户」等关键词
- 建立或改造文档管线需求
- 文档准出门禁建设（发布流程接入）
- 文档资产盘点与 TPL 映射需求

## 3. 执行步骤

1. **资产盘点**：枚举全部文档资产（路径/类型/受众/版本/模板依据），产出文档资产清单。
2. **仓库结构设计**：文档目录与版本分支策略（与代码同语义）；术语表单一真源位置。
3. **管线搭建**：构建流程（静态站或门户生成）+ 四项检查接入——
   - 死链检查：内部引用 + 外部 URL 双检
   - 交叉引用校验：文档间引用有效性与锚点存在性
   - 术语一致性扫描：术语表基线比对，同义漂移报告
   - 示例执行验证：API 文档示例批量执行（测试环境）
4. **CI 集成**：门禁接入发布流水线（文档门禁 FAIL 阻断发布，与 06 准出并联）；与 AETC 留痕协同（文档变更走 GATE 评审）。
5. **TPL 映射**：工程文档与 TPL-SRS/PDD/DDD/DBDD/IDD/ARC 的模板对应表，偏离项报告。
6. **交付**：管线配置 + 门禁报告 + 资产清单 + TPL 映射表。

## 4. 输入规范

```yaml
repo: 文档仓库路径
terms: 术语表路径
examples: 示例集路径（API 文档示例）
tpl_refs: TPL 模板引用清单（可自动探测）
ci_target: 目标 CI 平台（GitLab CI / GitHub Actions / Jenkins）
```

## 5. 输出格式

```markdown
# 文档工程管线配置报告
## 资产清单（路径/类型/版本/模板）
## 管线配置（构建/四项检查/门禁语义）
## 门禁报告：死链 | 交叉引用 | 术语一致 | 示例执行
## TPL 引用映射表（偏离项标注）
## CI 接入点与阻断语义
```

## 6. 质量标准

- 死链数 = 0（发布口径；构建口径 ≤ 阈值并全量登记）
- 术语一致率 ≥ 98%（扫描全量覆盖）
- 示例执行验证覆盖 API 文档全部端点示例
- TPL 映射率：工程文档 100% 有模板依据（无依据须登记豁免理由）
- CI 阻断语义明确（文档门禁与测试门禁并联，不可单方放行）

## 7. 风险控制

| 规则 | 内容 |
|------|------|
| RISK-01 | 文档门禁可被人工跳过（配置留后门）视为管线缺陷 |
| RISK-02 | 外链检查缺位（只查内链）导致发布后死链 |
| RISK-03 | 术语扫描白名单无登记（绕过机制滥用） |
| RISK-04 | 构建产物与源文档版本错位（发布旧版） |
| RISK-05 | 管线检查项可被注释关闭且无告警（防篡改语义） |
