# 技能模块：renewal_expansion_management

> 到期前 90 天风险分级（T-90 规则）、QBR 季度节奏、增购信号提报——承诺必须经 02 确认，临期救火判为违约。

## 1. 技能描述

本技能负责客户续约与增购的结构化管理：**T-90 规则**（到期前 90 天完成风险分级并启动对应动作——杜绝临期救火）、**QBR 节奏**（季度业务回顾：价值汇报+路线图对齐+增购窗口探测）、**增购信号识别与提报**（使用证据驱动，14 只识别不承诺——决策权归 02，放量评估归 13）。续约谈判支持提供健康度证据与价值量化材料，商务口径归销售/商务侧。

## 2. 触发条件

- 输入包含「续约」「续费」「增购」「挽回」「到期管理」「QBR」等关键词
- 合同到期表周期巡检或 QBR 筹备
- 挽回复盘需求

## 3. 执行步骤

1. **到期台账**：全量合同到期表（T-180/T-90/T-30 三档预警）。
2. **T-90 风险分级**：到期前 90 天按健康度趋势+关系信号分级（稳/关注/风险），风险级启动挽回动作包。
3. **QBR 执行**：价值汇报（健康度改善+业务成果量化）→ 路线图对齐（02 路线图口径）→ 增购窗口探测（记录信号不强推）。
4. **增购提报**：信号集（使用饱和/新场景请求/关键人询问）→ 提报单（带使用证据）→ 02 裁决排期。
5. **挽回复盘**：流失账户复盘（根因四维归因）→ 产品/流程改进项分流（02/AEGIS/11）。

## 4. 输入规范

```yaml
renewal_book: 合同到期表（账期/金额/层级）
health_trend: 健康度趋势（账户级）
signals: 增购信号集来源（使用数据/QBR 记录/请求工单）
qbr_schedule: QBR 客户清单与节奏
```

## 5. 输出格式

```markdown
# 续约与增购管理报告（周期）
## 到期台账（T-180/90/30 分布）
## 续约风险清单（分级+动作状态）
## QBR 材料（价值汇报/路线图对齐/信号记录）
## 增购提报单（证据附件）
## 挽回复盘（根因/改进分流）
```

## 6. 质量标准

- 到期账户 100% 在 T-90 前完成风险分级（临期才分级 = 流程违约）
- 增购提报 100% 带使用证据（无证据不提报）
- 承诺类输出 100% 经 02 确认（越权承诺零容忍）
- 流失账户 100% 有复盘与改进分流（VOC 闭环）
- QBR 材料 100% 含价值量化（禁止纯关系汇报）

## 7. 风险控制

| 规则 | 内容 |
|------|------|
| RISK-01 | T-30 仍有未分级账户 = 流程违约（升级复盘） |
| RISK-02 | 增购承诺未经 02 确认即对客户许诺（红线） |
| RISK-03 | 挽回靠折扣挽留（价值证据缺失）需高层会签 |
| RISK-04 | 流失复盘缺位（连续流失同类账户无归因） |
| RISK-05 | QBR 材料含未经 09 对齐的技术路线承诺 |
