# R4 增量实施 · 05-implementation（LR-STD-001）

> 输入：R3 全部门禁 PASS + D-R2-02 当前批次
> 循环单元门禁：D-R4-U-01 方案 → 实施 → D-R4-U-02 对照验证 → D-R4-U-03 切换记录
> 全局必输：D-R4-01 实施日志（持续）、D-R4-02 变更追溯矩阵（持续）

## 1. 阶段目标

按批次逐单元执行绞杀者循环：实现→对照→切换→观察。**这是唯一的编码实施阶段**，
单元内常规开发复用 SDLC 角色能力，本规则只定义重构特有的结构与门禁。

## 2. 单元循环（每个迁移单元严格执行）

### 2.1 方案（D-R4-U-01）
单元卡片细化：新旧对照的接口/数据/行为清单、实现要点、验证脚本清单、
回滚触发条件（引用批次预案）、预估切换窗口。

### 2.2 实施
- 新代码遵循 D-R1-03 采纳的工程规范；CR 质量门（P0/P1 清零）在提测前执行。
- 双轨期旧侧修补（仅限阻塞性缺陷）按 AETC R2 级管控：GATE 批准 + 检查点。
- 数据单元：迁移脚本按 D-R3-02 校验方案试跑（影子库）→ 校验报告附入 D-R4-U-02。

### 2.3 对照验证（D-R4-U-02）——铁律 4 的执行点
- 用 R3 金样本 + 特征测试在新侧执行，与旧侧基线逐项比对。
- **行为等价判定**：全部特征测试通过且金样本一致 → 等价；
  差异项逐条归类：①缺陷修复（在行为变更预算内，附确认）②环境差异（论证）③真回归（回退修复）。
- 数据单元：行数/主键/汇总数/抽样四层校验全过。
- 未取得等价证明（含已确认的预算内变更）→ **禁止切换**。

### 2.4 切换（D-R4-U-03）——AETC R3 级
- 切换前：AETC GATE_REQUEST（引用 D-R3-03 预案）→ 检查点（增量快照+流量标记）。
- 切换动作：按方案序列执行，全程留痕。
- 观察期：按 D-R2-02 预留时长监控独立指标；超阈值 → 按预案回滚，单元回炉。
- 切换记录：时间线、执行人、审批号、观察期结论、回滚点标识。

## 3. 全局资产

- **D-R4-01 实施日志**：按日/按事件追加（AETC STEP 记录的结构化汇总），不回改。
- **D-R4-02 变更追溯矩阵**：旧模块/表/接口 → 新模块/表/接口 的映射，
  每行附单元号与切换日期。**矩阵必须持续覆盖**：任何"旧侧已死、新侧未登记"的
  悬空映射都是验收阻塞项。

## 4. 批次推进与终止

- 批次内全部单元切换完成且观察期通过 → 批次关闭，进入下一批。
- 全部批次关闭（含退役批）→ R4 终止，进入 R5。
- 中途新增/剔除单元：走 D-R2-01 变更记录 + 本阶段日志双登记。
