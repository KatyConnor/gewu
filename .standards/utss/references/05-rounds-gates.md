# 05 测试轮次与准入准出门禁（Rounds & Gates）

本章定义「实践的测试轮」：每轮做什么、何时进入（准入）、何时结束（准出）、
何时暂停与恢复。这是防止「测一遍就宣布通过」的核心机制。

## 1. 轮次全景

```
开发提测 → T0 冒烟 → S1 功能测试 → S2 集成与系统 → S3 回归 → 门禁评估 → 准出
            │           │             │            │
            │ G1        │             │            │ G2
            └─ 失败即停  └─ 缺陷单流转 └────────────┴─ 修复后回炉重测受影响轮
```

- 轮次可按档位裁剪（references/09），但**任何档位 T0 冒烟不可省略**。
- 缺陷修复引入的再测试：受影响的轮次重跑受影响范围，不是「改一行就只测那一行」
  （影响面按 Step 1 的分析，diff 之外的连带行为也要回归）。

## 2. 各轮准入/准出标准

### T0 冒烟测试
- **准入**：提测包可构建、可部署/可启动；冒烟池用例（P0）就绪。
- **准出（G1）**：冒烟用例 100% 通过。
- **失败处置**：打回开发，修复后重新 T0（不允许带病进入 S1）。

### S1 功能测试
- **准入**：G1 通过；**用例完备性检查通过**（references/03 第 5 节：12 字段齐备 + 功能覆盖核对 + 数据/依赖可满足）；单测准入检查通过（references/04 第 1 节）。
- **准出**：计划内用例执行完毕（通过/失败/阻塞三态都有记录）；失败项全部提缺陷单；
  致命/严重缺陷已提单且定级无争议。

### S2 集成与系统测试
- **准入**：S1 准出；致命/严重缺陷修复版本就绪（或按风险决定并行）；环境/数据就绪。
- **准出**：集成与选定的非功能类型执行完毕并留数据；接口契约断言通过。

### S3 回归测试
- **准入**：缺陷修复完成、产出新提测包；回归范围清单确定（修复验证 + 影响面 + 抽查）。
- **准出（G2）**：致命/严重缺陷 100% 关闭；一般缺陷有结论（修复/延期/豁免——延期与豁免必须用户明示确认）；
  修复验证用例 100% 通过；未发现修复引入的新缺陷（发现则回到对应轮次）。

## 3. 暂停与恢复标准

**暂停条件（触发任一即暂停并通知用户）**：
- 阻塞缺陷：主流程不可用且无绕行方案，导致 ≥30% 用例无法执行
- 环境不可用且预计恢复 > 半个工作单位
- 需求/接口剧烈变更，测试计划基础失效

**恢复条件**：阻塞解除 + 受影响用例重新评估（补删改）+ 恢复点重新准入。

## 4. 缺陷收敛判定（S3 何时可以停）

行业通行判据（按档位选择）：

| 判据 | 说明 | 适用 |
|---|---|---|
| 遗留清零 | 无遗留致命/严重缺陷，一般缺陷有结论 | 全档位硬条件 |
| 收敛曲线 | 最后一轮新发现缺陷数 ≤ 上一轮的 20% 且连续一轮零致命 | C/D |
| 执行完尽 | 计划用例执行率 100%（阻塞单列并豁免说明） | 全档位硬条件 |
| 密度门限 | 缺陷密度 ≤ 阈值（references/06） | C/D 参考 |

**防过测/欠测**：连续两轮零新缺陷且收敛判据满足 → 停止追加测试，进入门禁评估；
若仍源源不断发现缺陷 → 不是「再测一轮」能解决的，回到 Step 1 重新评估风险与范围。

## 5. 门禁汇总表（G0-G3）

| 门禁 | 时点 | 硬条件 | 不达标处置 |
|---|---|---|---|
| G0 计划门禁 | Step 2 末 | 测试项 100% 追溯 Step 1；轮次与环境明确 | 补计划，不得开测 |
| G1 冒烟门禁 | T0 末 | 冒烟用例 100% 通过 | 打回修复，重新 T0 |
| G2 回归门禁 | S3 末 | 致命/严重清零；一般有结论；修复验证通过 | 继续修复回炉 |
| G3 准出门禁 | Step 7 | 覆盖率达档位阈值；退出准则逐条满足 | PASS-WITH-RISK 或 FAIL |

**G3 未达标的唯一合法出路**：用户明示接受 → PASS-WITH-RISK，报告中逐条列残余风险 +
建议监控项（右移兜底）；**任何人都不能把 FAIL 静默改写成 PASS**。
