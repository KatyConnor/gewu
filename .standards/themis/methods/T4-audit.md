# T4 审计细则 — 过程合规与留痕审计（THEMIS · V1.9.27 批3 · ISO 19011 对齐）

> 正本出处：ISO 19011（管理体系审核指南）——审计独立性/证据/发现分级三原则 +
> AETC trace 为主要取证面。T1/T2/T3 评审对象是**产物**；T4 审计对象是**过程与留痕**。

## 一、审计独立性（红线·加严）

- 审计员不得审计**自己作为执行者**产出的留痕会话（比评审独立性更严：
  留痕的产出者天然是"被审过程的执行者"——单 Agent 形态下按 spec-themis.yaml
  independence_equivalence 三件套执行，且 recheck_evidence 须附对账差异明细）。

## 二、四步流程

1. **计划**（并入 RR）：定范围（哪批 trace/哪个时段）+准则（AETC 五铁律+R 分级清单）+抽样分层；
2. **取证**：按 §三 抽样 → 逐条对账；
3. **报告**：FINDING/RPT 复用（severity 映射见 §四）；
4. **跟踪**：CAPA 复用；证实**造假**（留痕与实际不符且无回滚记录）→ AETC §八红线事件，
  本规范无权降级处理。

## 三、trace 抽样分层（默认比例·项目可在 RR.standard_set 覆盖）

| 层 | 事件级别（AETC） | 默认抽样 | 对账项 |
|---|---|---|---|
| 全审 | R0 红线事件 | **100%** | 事件真实性+处置完整性 |
| 强抽 | R1 关键决策/写操作 | ≥30% | 先留痕后行动的时序+产物实存对账 |
| 中抽 | R2 常规修改 | ≥10% | 单据链（trace_ref↔产物↔单据）互锁 |
| 弱抽 | R3 只读/查询 | ≥5% | 声称的读取对象在位 |

> 对账方法：留痕行声称的（路径/哈希/单据号）逐项实存验证——**模型自报不算数，
> 对账过才算**（体系通用纪律在审计域的落点）。

## 四、发现分级映射

| 审计发现 | severity | 路由 |
|---|---|---|
| 留痕造假/红线未处置 | S1（阻断） | AETC §八 + 留痕类路由→稽核复核 |
| R1 应留未留（先行动后补记） | S2 | 留痕类→AETC 稽核 |
| R2 抽样不合格率 >20% | S3 | 体系类→META（判型收紧 demotion_signal） |
| 记录规范瑕疵（字段/格式） | S4 | 文档类→退回产出方 |

## 五、审计报告增补字段（RPT 扩展·type: T4 时必填）

```yaml
audit:
  scope: <trace 批次/时段>
  sampling: {R0: "100%/n=3", R1: "30%/n=47", R2: "10%/n=120", R3: "5%/n=61"}
  failed_rate: {R1: x%, R2: y%}   # 分层不合格率（>20% 升 S3）
```
