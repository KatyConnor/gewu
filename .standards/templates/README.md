# 全局公共文档模板库（STD-TPL-001）

> 版本 V1.1 · 2026-10-07 · 层级：**hub 级公共资产（全局可引用）**｜V1.1：+交付文档族三张（UM/APIREF/RN，12 号卡接线）
> 标准依据：GB/T 8567-2006《计算机软件文档编制规范》+ ISO/IEC/IEEE 29148:2018（需求工程）+ IEEE 1016-2009（设计描述）+ IEEE 42010（架构描述思想）+ C4/4+1 视图模型
> 理论依据：Chikofsky & Cross 设计恢复分类学（1990）· von Mayrhauser & Vans 程序理解集成元模型（1995）· 软件考古学 · Feathers 接缝理论（2004）

## 1. 这是什么

面向**从零理解/重建文档**的场景（无文档遗留项目、逆向还原、正向开发皆可）的行业标准级文档模板集。
所有规范（LPU/LR/SDLC 等）与任意 Agent 均可按引用协议直接引用，**不改变各规范自身的产出契约，只提供成文标准**。

## 3. 引用协议（全局统一）

1. **复制即用**：模板章节顺序与章节名不可增删（门禁按章节名校验）；章内条目可按项目裁剪，裁剪必须留痕（"本项不适用：原因"）。
2. **占位符**：`{{VAR}}` 必须全部替换；示例行（`例：`开头）写完即删。
3. **证据锚点**：逆向场景每条关键结论带 `【证据】路径:行号`；正向场景换成设计依据条目。
4. **置信度**：逆向产物沿用 LPU 的 [A]/[B]/[C] 标注体系；正向开发省略。
5. **质检点**：每份模板文末"质量检查点"是人工/门禁双核对清单，交付前逐项过。

## 4. 与 LPU V1.3 的关系

LPU 六步理解序列（技术栈→整体架构→层次与能力→表结构→逐项功能→交叉验证）的成文产物
（SRS/PDD/DDD/DBDD/IDD/FD/ARC）**必须**引用本库模板；模板库独立演进，供其他规范复用。
