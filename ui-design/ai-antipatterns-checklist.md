# AI UI设计自检清单（25项交付门禁）

> 用途：AI生成界面代码后、交付前的强制自检。25项全部通过才允许交付。
> 来源：《AI前端UI设计规范体系》V1.0 第十三章。
> 使用方式：AI自我核对时逐项打勾并在回复末尾输出自检结果表；人工验收时按此清单核查。

## 一、色彩（5项）

- [ ] **CHK-01** 无紫色/蓝紫渐变背景，无大面积高饱和色块
- [ ] **CHK-02** 主色唯一，非框架默认色；强调色仅用于关键CTA与状态
- [ ] **CHK-03** 色彩面积符合60-30-10：中性色占大头，主色克制点缀
- [ ] **CHK-04** 语义色（成功/警告/错误/信息）使用标准组合，状态有图标或文字冗余传达
- [ ] **CHK-05** 深色模式下无纯黑#000、纯白#fff，无彩色发光

## 二、排印（4项）

- [ ] **CHK-06** 无渐变文字；标题字重≤700，无900字重标题
- [ ] **CHK-07** 字号全部落在音阶（12/14/16/20/24/32/48），无任意值
- [ ] **CHK-08** 正文≥14px、行高1.6；标题行高≤1.3
- [ ] **CHK-09** 中英混排有空格；中文界面无Title Case

## 三、布局（4项）

- [ ] **CHK-10** 无三等分卡片阵列展示等价信息（有主从/差异化布局替代）
- [ ] **CHK-11** 间距全部命中8点网格令牌，无魔数
- [ ] **CHK-12** 正文行长≤75字符（约42中文字），主内容区有最大宽度限制
- [ ] **CHK-13** 信息密度与产品语境匹配（B端紧凑/营销宽松但内容不空心）

## 四、组件（5项）

- [ ] **CHK-14** 圆角≤12px（胶囊除外）；阴影≤2层；无毛玻璃
- [ ] **CHK-15** 每屏仅一个实心主按钮
- [ ] **CHK-16** 交互组件五态完备（默认/悬停/激活/禁用/焦点），focus-visible可见
- [ ] **CHK-17** 表单标签常驻，错误态有文字说明（不只靠红色）
- [ ] **CHK-18** 优先使用了项目组件库，自定义组件仅做主题化

## 五、动效与图标（3项）

- [ ] **CHK-19** 无弹跳/漂浮/循环动画；入场动画≤1组且≤200ms
- [ ] **CHK-20** 过渡仅用opacity/transform；时长命中规范（150/200/280ms）
- [ ] **CHK-21** 无emoji图标；图标来自单一图标库、风格统一、有尺寸与aria-hidden

## 六、文案（3项）

- [ ] **CHK-22** 黑名单词汇零命中（赋能/打造/解锁/释放/极致/一站式/新纪元等）
- [ ] **CHK-23** 无Lorem ipsum/假人名/假数据；示例数据业务自洽
- [ ] **CHK-24** 界面文案零感叹号；标题含具体信息而非空洞口号

## 七、无障碍与响应式（1项）

- [ ] **CHK-25** 对比度达标（正文≥4.5:1）、触控目标≥44px、移动端无横向溢出

---

## 自检结果输出格式

```
自检结果：25/25 通过
未通过项：无（或列出项号与修正说明）
```

## 使用说明

1. **AI自检**：生成代码后按清单逐项核对，输出上述结果块。未通过项当场修复后复检
2. **人工验收**：按清单快速走查，10分钟内可完成
3. **CI集成**：CHK-22（黑名单）、CHK-23（占位数据）可脚本化检索，接入流水线门禁
