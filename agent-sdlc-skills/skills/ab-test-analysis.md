# 技能模块：ab_test_analysis

> A/B 测试方案设计与结果分析，含样本量计算、显著性检验、置信度标注。

## 1. 技能描述

本技能提供端到端 A/B 测试支持：方案设计（指标定义、分流策略、样本量计算）→ 实验执行 → 结果分析（显著性检验、置信度标注、异质性分析）→ 迭代建议。覆盖二项分布（转化率）、连续型（GMV、时长）、计数型（点击次数）三类指标，支持 A/A、A/B、A/B/n 多种实验形态。

## 2. 触发条件

- 输入包含「A/B 测试」「实验设计」「显著性检验」「置信度」「对照实验」等关键词
- 已明确测试目标（提升转化 / 优化体验 / 验证策略）
- 已定义核心指标与基线值
- 存在历史数据用于样本量计算

## 3. 执行步骤

1. **测试目标澄清**：明确待验证假设（如「新首页提升转化率 5%」）、主指标、护栏指标、反向指标。
2. **指标定义**：明确指标口径、计算方式、统计周期。
3. **样本量计算**：基于历史基线、最小可检测效应（MDE）、显著性水平 α、统计功效 β 计算所需样本量。
4. **分流策略设计**：哈希分流、分层分流、互斥实验、正交实验，确保样本均衡。
5. **实验时长预估**：基于日活、样本量、业务周期（覆盖完整周 / 月）。
6. **实验执行监控**：监控分流均衡性、指标稳定性、异常流量。
7. **结果分析**：
   - 显著性检验（Z 检验 / T 检验 / 卡方检验）
   - 置信区间标注
   - 效应量计算（Cohen's d）
   - 异质性分析（按用户群体拆分）
8. **迭代建议**：基于结论输出「全量上线 / 继续实验 / 终止实验 / 调整方案」建议。

## 4. 输入规范

```yaml
任务类型: A/B测试方案设计
测试目标: 验证新首页提升注册转化率
主指标: 注册转化率
护栏指标: 页面加载时长、错误率
反向指标: 客诉率
历史基线: 转化率 12%
MDE: 1%（相对提升 8.3%）
显著性水平: 0.05
统计功效: 0.8
日活: 100000
实验形态: A/B
```

## 6. 质量标准

- 样本量必须基于统计功效计算，禁止随意拍数
- 显著性水平默认 α=0.05，统计功效 β≥0.8
- 实验时长必须覆盖完整业务周期（≥ 7 天，含周末）
- 分流必须做均衡性检验（SRM 检验）
- 结论必须标注 p 值与置信区间
- 护栏指标恶化即使主指标显著也需评估是否上线

## 7. 风险控制

| 规则 | 内容 |
|------|------|
| RISK-01 | 样本量未达统计要求禁止出结论 |
| RISK-02 | 分流不均衡（SRM 显著）禁止出结论 |
| RISK-03 | 实验时长不足（< 7 天）禁止下结论 |
| RISK-04 | 护栏指标恶化超过 5% 禁止全量上线 |
| RISK-05 | 涉及定价、风控等高风险策略必须叠加兜底机制 |
| RISK-06 | 实验数据必须脱敏，禁止含真实用户身份 |
| RISK-07 | 结论必须标注统计置信度，禁止绝对化表述 |

```yaml
传递字段: [实验方案, 样本量, 实验结论, p值, 置信区间, 迭代建议]
```
