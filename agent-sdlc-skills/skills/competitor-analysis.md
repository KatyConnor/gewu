# competitor_analysis | 同业机构对标分析

## 1. 技能描述

本技能面向托管业务调研专家，提供同业机构的多维度对标分析能力。覆盖头部银行、头部券商、第三方托管机构等市场前 10-20 名机构，从产品体系、客群策略、展业渠道、系统能力、市场份额五维度构建对比矩阵，识别自身差距与可复用经验，输出可落地的提升建议。

## 2. 触发条件

满足以下任一条件即触发：
- 输入包含「同业对标 / 竞品分析 / 头部银行 / 头部券商 / 市场份额」等关键词
- 业务方要求对标同业机构的某一维度能力
- 涉及新产品立项前的竞品分析、年度同业对标报告、市场份额复盘
- 角色 00 被激活且场景为「同业对标」

## 3. 执行步骤

1. **对标框架确认**：明确机构类型、对标维度、市场范围三要素
2. **同业机构扫描**：识别目标市场前 10-20 名托管机构，输出对标清单
3. **多维度信息采集**：按产品 / 客群 / 渠道 / 系统 / 份额五维度采集数据
4. **数据来源核验**：每条数据标注来源机构、发布时间、数据口径、样本量
5. **结构化对比分析**：构建对比矩阵表，识别差异点与共性点
6. **差距识别与优势提炼**：对照自身现状，输出差距清单与优势清单
7. **可复用经验提炼**：从同业最佳实践中提炼可复用产品模式、运营打法
8. **提升建议输出**：按 ROI 与落地难度排序输出提升建议
9. **风险控制校验**：标注数据来源、置信度、样本量声明

## 4. 输入规范

```yaml
机构类型: "城商行（托管部）"
市场范围: "国内"
对标对象: ["头部股份制银行", "头部城商行", "头部券商"]
对标维度: ["产品体系", "客群策略", "展业渠道", "系统能力", "市场份额"]
自身现状基线: "（脱敏后的内部现状）"
时间范围: "近 24 个月"
输出格式: "结构化对比矩阵 + 提升建议清单"
```

## 5. 输出格式

```markdown
## 同业对标结果

### 一、对标机构清单
| 机构名称 | 类型 | 市场份额 | 数据来源 |

### 二、多维度对比矩阵
| 维度 | 同业 A | 同业 B | 自身 | 差距 |

### 三、差距识别 + 优势提炼
- 主要差距：[清单]
- 自身优势：[清单]

### 四、可复用经验清单
| 经验项 | 来源机构 | 适用场景 | 落地难度 |

### 五、提升建议（按 ROI 排序）
```

## 6. 质量标准

- 对标机构清单不少于 5 家，建议覆盖 10-20 家
- 每条数据标注来源机构 + 发布时间 + 数据口径 + 样本量
- 样本量低于 5 家机构时必须标注「样本量不足，结论仅供参考」
- 所有结论标注置信度（高 / 中 / 低）
- 提升建议必须附落地难度评估与预期收益估算
- 标注数据时效，超期 12 个月需重新核验

## 7. 风险控制

| 规则编号 | 风险点 | 控制动作 |
|---------|--------|---------|
| R-01 | 数据来源不可追溯 | 强制标注来源机构 + 发布时间 + 数据口径 |
| R-02 | 多源数据矛盾 | 列出多源数据并标注差异原因 |
| R-03 | 样本量不足 | <5 家机构必须标注「仅供参考」 |
| R-04 | 内部数据未脱敏 | 自身现状数据需脱敏处理 |
| R-05 | 绝对性建议 | 禁止「必须赶上 / 一定要做」等措辞 |
| R-06 | 调整空间预留不足 | 所有结论附加 ±10% 调整空间 |
| R-07 | 时效过期未声明 | 标注数据发布日期，超期需重新核验 |
