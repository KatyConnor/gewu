# 技能模块：data_metrics_design

> 指标体系设计与全链路埋点方案。

## 1. 技能描述

本技能根据业务类型与核心目标，设计分层指标体系（北极星 → 一级 → 二级 → 三级）与全链路埋点方案。覆盖 C 端（DAU / MAU / 转化率 / 留存率）、B 端（完成率 / 提效比）、AI（意图准确率 / 任务完成率）三类场景。输出指标字典、埋点文档、看板设计方案。

## 2. 触发条件

- 输入包含「指标体系」「埋点方案」「DAU / MAU」「转化率」「留存率」「北极星指标」等关键词
- 已明确业务类型（C 端 / B 端 / AI / 混合）
- 已明确核心业务目标
- 新产品立项 / 重大版本上线 / 数据驱动决策场景

## 3. 执行步骤

1. **业务类型识别**：识别 C 端 / B 端 / AI / 混合型，匹配对应指标体系模板。
2. **北极星指标定义**：明确唯一核心指标，代表产品长期价值。
3. **分层指标体系设计**：北极星指标（1 个）→ 一级指标（3-5 个核心驱动）→ 二级指标（10-20 个过程）→ 三级指标（30+ 个执行细节）。
4. **分场景指标细化**：C 端（DAU/MAU/留存/转化/时长/LTV/CAC）、B 端（完成率/提效比/NPS/续费率/活跃度）、AI（意图准确率/任务完成率/内容合规率/幻觉率/满意度）。
5. **漏斗设计**：识别核心转化漏斗，定义各环节指标。
6. **埋点方案设计**：事件埋点（浏览/点击/表单/订单）+ 属性埋点（用户/设备/业务属性）+ 用户标识（用户 ID/设备 ID/会话 ID）。
7. **看板设计**：核心指标看板 + 漏斗看板 + 留存看板 + 实时大屏。
8. **输出指标字典与埋点文档**：明确定义、口径、计算方式、责任人。

## 4. 输入规范

```yaml
任务类型: 指标体系设计
业务类型: C端电商 + AI智能推荐
核心目标: 提升用户购买转化与复购
北极星候选: GMV / 复购率 / DAU
用户旅程: 浏览→搜索→加购→下单→支付→复购
数据平台: 神策 + 自建数仓
埋点SDK: 神策SDK
```

## 6. 质量标准

- 北极星指标必须唯一且代表长期价值
- 指标定义必须清晰、可计算、无歧义
- 埋点必须覆盖核心漏斗全链路，无断点
- 指标口径必须与数据团队对齐
- 埋点方案必须经过埋点测试验证
- 看板必须支持按时间、渠道、用户群体下钻

## 7. 风险控制

| 规则 | 内容 |
|------|------|
| RISK-01 | 北极星指标必须唯一，禁止多个并存，定义必须明确口径 |
| RISK-02 | 埋点必须覆盖用户全生命周期，禁止断点，未验证不上线 |
| RISK-03 | 埋点数据不得包含敏感个人信息（明文） |
| RISK-04 | AI 指标必须有人工标注基线，禁止纯算法自评 |
| RISK-05 | 跨端数据必须做用户身份打通，避免数据孤岛 |
