# 技能模块：refactoring_guide

> 代码重构方案设计，匹配设计模式优化代码质量。

## 1. 技能描述

本技能基于代码异味识别与设计模式匹配，输出可落地的重构方案。覆盖工厂、代理、策略、观察者、适配器、装饰器等 23 种 GoF 设计模式。强调小步重构、功能一致性保持、测试先行的安全网，并输出前后对比与配套单元测试。

## 2. 触发条件

- 输入包含「代码重构」「设计模式」「解耦」「可复用」「代码异味」等关键词
- 存在待重构代码或代码评审报告
- 识别到以下异味：重复代码、长方法、大类、过长参数列表、发散修改、霰弹式修改、数据泥团

## 3. 执行步骤

1. **代码异味扫描**：使用 SonarQube / Checkstyle / ESLint 识别异味，定位问题代码段。
2. **识别重构点**：性能瓶颈（N+1、循环嵌套）、设计缺陷（紧耦合、违反 SOLID）、安全风险（注入、越权）。
3. **匹配设计模式**：
   - 工厂模式：对象创建解耦
   - 代理模式：增强、缓存、权限控制
   - 策略模式：算法切换、规则引擎
   - 观察者模式：事件驱动、解耦通知
   - 适配器模式：接口适配、兼容老代码
   - 装饰器模式：功能扩展、不改变原结构
4. **制定重构方案**：小步分解，每步可独立提交，保持测试通过。
5. **生成配套单测**：调用 `unit_test_generator`，确保重构前后行为一致。
6. **执行重构**：实施代码改动，每步运行全量测试。
7. **前后对比验证**：功能等价性 + 性能不退化 + 覆盖率不下降。
8. **输出报告**：重构方案、前后对比、设计模式说明、单测清单。

## 4. 输入规范

```yaml
任务类型: 代码重构
源代码路径: src/main/java/com/xxx/LegacyOrderService.java
异味报告: [SonarQube 报告链接]
重构目标: 提升可扩展性 + 消除重复代码
约束条件: 不改变外部 API 行为
性能基线: P99 < 200ms
```

## 6. 质量标准

- 重构前后功能行为 100% 一致（全量测试通过）
- 性能不退化（响应时间浮动 ≤ 5%）
- 覆盖率不下降，建议提升 ≥ 5%
- 代码圈复杂度降低 ≥ 30%
- 重复代码率降低 ≥ 50%
- 每个设计模式应用必须有充分理由，禁止为模式而模式

## 7. 风险控制

| 规则 | 内容 |
|------|------|
| RISK-01 | 重构前必须备份原代码 + 建立测试安全网 |
| RISK-02 | 重构前后必须全量测试通过，性能不退化 |
| RISK-03 | 禁止重构时改变外部 API 行为（兼容性） |
| RISK-04 | 大型重构必须分批合入，单次 PR ≤ 500 行 |
| RISK-05 | 核心模块重构必须 Code Review + 灰度发布 |
| RISK-06 | 禁止「大爆炸」式重构，必须小步迭代 |
