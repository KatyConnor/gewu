# industry_policy_search | 行业政策定向检索与解读

## 1. 技能描述

本技能面向托管业务调研专家，提供监管政策的定向检索、结构化解读、业务影响评估与合规提示输出能力。覆盖中国人民银行（PBOC）、国家金融监督管理总局（NFRA）、中国证监会（CSRC）、国家外汇管理局（SAFE）等监管机构发布的政策文件。目标是将庞杂的政策原文转化为可执行的业务行动建议，避免合规滞后。

## 2. 触发条件

满足以下任一条件即触发：
- 输入包含「政策检索 / 政策解读 / 监管新规 / 资管新规 / 托管业务管理办法」等关键词
- 业务方明确要求评估某项业务对监管政策的合规性
- 涉及托管资格申请、跨境业务展业、合规自查等强监管场景
- 角色 00 被激活且场景为「政策研判」

## 3. 执行步骤

1. **检索需求确认**：明确政策主题、监管机构、时间范围、业务范围四要素，缺失任一项需主动询问
2. **检索关键词构建**：按主题 + 文号 + 监管机构 + 发布日期组合关键词
3. **政策原文定向检索**：通过监管机构官网、行业资讯库检索，标注原文链接与发布日期
4. **政策条款结构化解析**：拆解政策原文为条款清单，提取合规义务、影响范围、生效时点
5. **业务影响评估**：将条款映射到托管业务的产品 / 客群 / 流程 / 系统四维度
6. **趋势预判**：基于政策轨迹与行业动态，预判 1-3 年监管走向
7. **行动建议输出**：按优先级排序输出可执行建议
8. **风险控制校验**：标注政策来源、置信度、时效性、合规确认要点

## 4. 输入规范

```yaml
政策主题: "私募基金托管监管要求"
监管机构: ["证监会", "金融监管总局"]
时间范围: "2024-01-01 至 2025-12-31"
业务范围: "私募基金托管资格申请"
输出语言: "中文"
输出格式: "结构化报告 + 行动建议清单"
```

## 5. 输出格式

```markdown
## 政策研判结果

### 一、政策清单表
| 监管机构 | 文号 | 发布日期 | 核心条款摘要 | 影响等级 |

### 二、业务影响评估
- 影响产品：[清单]
- 影响客群：[清单]
- 影响流程：[清单]
- 影响系统：[清单]

### 三、1-3 年趋势预判
- 政策走向 + 关键驱动因素

### 四、合规提示清单
- 必复核项 + 建议复核部门

### 五、行动建议（按优先级）
```

## 6. 质量标准

- 每条政策引用必须标注：监管机构 + 文号 + 发布日期 + 原文链接
- 所有结论标注置信度（高 / 中 / 低），低置信度结论不作为决策唯一依据
- 涉及强监管领域必须单独列出「合规确认要点」清单
- 1-3 年趋势预判必须附「预测假设」清单，假设变更需重新预判
- 标注信息时效（截至 YYYY-MM-DD），超期 6 个月需重新核验

## 7. 风险控制

| 规则编号 | 风险点 | 控制动作 |
|---------|--------|---------|
| R-01 | 政策来源不可追溯 | 强制标注监管机构 + 文号 + 原文链接 |
| R-02 | 不同监管机构政策冲突 | 标注冲突点，提示由合规部门裁定 |
| R-03 | 政策时效过期 | 标注截至日期，超期需重新核验 |
| R-04 | 绝对性建议 | 禁止「必须 / 绝对 / 一定」等措辞 |
| R-05 | 内部数据未脱敏 | 内部业务现状数据需脱敏处理 |
| R-06 | 调整空间预留不足 | 所有结论附加 ±10% 调整空间声明 |
