# prd_generation | PRD 文档生成

## 1. 技能描述

本技能面向产品经理 / 产品专家，提供从需求清单到完整 PRD 文档的标准化生成能力。覆盖 PRD 七大模块：需求背景与目标、功能清单（P0-P3 优先级）、交互逻辑（流程图 + 状态机）、业务流程（角色 + 触发条件 + 业务规则）、验收标准（功能 + 业务 + 数据）、数据监控指标（核心 KPI + 过程指标）、AI 预期提示模块（AI 功能必含）。

## 2. 触发条件

满足以下任一条件即触发：
- 输入包含「PRD / 产品需求文档 / 功能清单 / 交互逻辑 / 验收标准」等关键词
- 业务方要求撰写新产品 PRD 或迭代版本 PRD
- 角色 02 被激活且场景为「需求洞察 + PRD 撰写」或「AI 智能体专项设计」

## 3. 执行步骤

1. **需求确认前置**：必须完成需求确认，禁止跳过需求确认直接撰写 PRD
2. **需求规格说明梳理**：将原始需求转化为结构化需求规格
3. **功能清单整理**：按 P0 / P1 / P2 / P3 分级，每个功能附简述
4. **交互逻辑设计**：输出流程图 + 状态机 + 异常处理分支
5. **业务流程定义**：明确角色 + 触发条件 + 业务规则 + 异常分支
6. **验收标准制定**：每个功能必须含功能验收 + 业务验收 + 数据验收
7. **数据监控指标设计**：定义核心 KPI + 过程指标 + 数据看板
8. **AI 预期提示模块**：AI 功能必含能力边界 + 不确定性 + 人工接管机制 + 用户预期文案 + 反馈机制五要素
9. **PRD 评审对齐**：与研发 / 架构师对齐技术方案与可行性
10. **风险控制校验**：标注置信度、调整空间、AI 特有风险

## 4. 输入规范

```yaml
业务需求: "为机构客户设计 AI 驱动的智能投研助手"
赛道: "B 端 + AI 智能体"
需求清单: "[来自角色 01 的需求清单]"
功能优先级: "P0/P1/P2/P3"
技术约束: "私有化部署，支持主流开源大模型"
上线时间: "3 个月内 MVP"
强监管判定: "是 / 否"
输出格式: "完整 PRD + AI 预期提示模块"
```

## 5. 输出格式

```markdown
## PRD 文档

### 一、需求背景与目标
- 业务背景 + 用户痛点 + 业务目标 + 成功标准

### 二、功能清单（P0/P1/P2/P3）
| 功能名 | 优先级 | 简述 | 验收标准 |

### 三、交互逻辑
- 流程图 + 状态机 + 异常处理

### 四、业务流程
- 角色 + 触发条件 + 业务规则 + 异常分支

### 五、验收标准
- 功能验收 + 业务验收 + 数据验收（禁止模糊描述）

### 六、数据监控指标
- 核心 KPI + 过程指标 + 数据看板设计

### 七、AI 预期提示模块（AI 功能必含）
- 能力边界 + 不确定性 + 人工接管机制 + 用户预期文案 + 反馈机制
```

## 6. 质量标准

- PRD 必含七大模块，AI 功能必含「AI 预期提示」模块
- 每个功能必须含明确验收标准，禁止「基本功能」「正常使用」等模糊描述
- 每个功能必须含核心 KPI 与过程指标
- 交互逻辑必须含异常处理分支
- AI 功能必须明确能力边界（L1-L5 分级）与人工接管触发条件
- 所有方案标注置信度（高 / 中 / 低）与 ±10% 调整空间
- 强监管赛道必须输出合规确认要点

## 7. 风险控制

| 规则编号 | 风险点 | 控制动作 |
|---------|--------|---------|
| R-01 | 跳过需求确认直接写 PRD | 强制需求确认前置 |
| R-02 | PRD 模块缺失 | 校验七大模块齐全，AI 功能必含预期提示 |
| R-03 | 验收标准模糊 | 禁止「基本功能」等模糊描述 |
| R-04 | 数据监控指标缺失 | 每个功能必须含核心 KPI 与过程指标 |
| R-05 | AI 能力过度承诺 | 必须明确能力边界 + 不确定性提示 |
| R-06 | AI 缺人工接管机制 | 必须设计触发条件 + 接管流程 |
| R-07 | 绝对性建议 | 禁止「必须 / 绝对 / 一定」等措辞 |
| R-08 | 强监管赛道合规缺位 | 必须调用角色 07 复核 |

|---------|---------|---------|
| 角色 01 业务需求分析师 | PRD 撰写前 | 需求清单 + 用户画像 + 用户旅程初稿 |
| 角色 03 技术架构师 | 技术评审对齐 | 完整 PRD + 交互逻辑 + 业务流程 + AI 预期提示 |
| 角色 04 全栈开发工程师 | 开发实施 | 技术评审对齐后的 PRD + 验收标准 |

| 角色 07 合规专家 | AI 功能合规审查 | AI 能力边界 + 数据合规审查需求 |
| 角色 10 项目管理与敏捷教练 | 研发排期 | 功能清单 + 优先级 + 里程碑建议 |
